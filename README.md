# 狐火行 Kitsunebi

2D 和風妖怪探險尋寶 RPG（網頁、手機觸控）。規格見 [docs/PRD.md](docs/PRD.md)。

## 開發

```bash
npm install
npm run dev            # 本機開發伺服器（--host，同網路的手機可連）
npm test               # 單元測試（Vitest）
npm run build          # 型別檢查＋打包成單一 dist/index.html
npm run build:artifact # 另外產生可發佈成 Claude Artifact 的 dist-artifact/kitsunebi.html
npm run assets         # 重新產生佔位素材（tileset、主角、狐火村地圖）
```

## 目前進度：全四章＋隱藏章完成（三種結局）

開新遊戲先選職業與難度，接著：
燈的家 → 狐火村 → 神社找宮司爺爺 → 迷霧竹林 → 古井 → 回神社報告（序章完）→ 古井地城 B1 → B2 → B3 → 土蜘蛛的巢穴 → 第一章完。

**第四章：鬼之城（最終章）與結局**
- 第三章結束後找宮司爺爺開始；迷霧竹林東邊的注連繩解開，前往鬼之城
- 前幾章 Boss 的寶物變成鑰匙：銀鑰匙（城下的銀箱）、河童王的冠（一樓的水封之門）、大天狗的團扇（二樓的風之門）
- 鬼之城一樓（拉桿＋推石、茨木童子守衛寶箱、牢房裡的小鬼）、二樓（燈籠順序「鬼→人→狐」）、天守閣
- 新怪物：餓鬼、赤鬼、青鬼、鬼火、茨木童子（精英）
- Boss 酒吞童子：鐵棒重擊、火焰吐息（留下火焰地帶）→ 召喚餓鬼、衝撞 → 連續暴衝；打破四角的神便鬼毒酒酒樽讓它醉倒
- 結局（PRD 2.6）：羈絆值 ≥ 10 且神器碎片 5 枚 → 隱藏章「黃泉之門」；否則怒火值較高 → 結局 A「封印」，其餘 → 結局 B「共存」
- 隱藏章：和夜叉丸一起對抗百鬼之主（前幾章 Boss 的招式全都會），打碎四角的結界石讓它動不了；打倒後是真結局
- 神器碎片：第 1～4 章密室寶箱各 1 枚，第 5 枚是收集度 100% 的獎勵；舊存檔開過的碎片寶箱在最終章開始時補發
- 結局後有片尾名單，可以回到標題或繼續遊玩；新背景音樂「鬼之城」「黃泉之門」

**第三章：天狗山**
- 第二章結束後找宮司爺爺開始；狐火村西邊的注連繩解開，前往天狗山
- 天狗山的三個試煉：力（打倒兩波妖怪）、智（回答天狗的謎題）、速（25 秒內點亮 4 座石燈籠），全部通過才能登頂
- 山風：風區會把人往一個方向推（閃避、突刺中不受影響）
- 天狗寺：拉桿＋推石頭開門、大鴉（精英）守衛寶箱、裂牆密室
- 新怪物：烏天狗（丟羽毛）、山童（跳躍衝撞）、鎌鼬（很快的突進）、大鴉（精英）
- Boss 大天狗：羽毛扇射、俯衝斬 → 召喚烏天狗、追著人跑的旋風 → 狂暴、把人吹開的狂風；敲響四角的神木之鈴讓它掉下來（硬直 3.5 秒、傷害 ×1.5）
- 劇情：夜叉丸的身世揭曉（母親是妖怪，被三百年前的結界拆散）；打倒大天狗後回答「打算如何對待夜叉丸」（羈絆值／怒火值）
- 第四階裝備 8 件、鍛冶屋新配方 2 張、支線「山太的柿子」、告示板新委託與懸賞、新素材（天狗的羽、鎌鼬的爪）、新背景音樂「天狗山」

**第二章：河童沼澤**
- 第一章結束後找宮司爺爺開始；狐火村南邊的注連繩解開，前往河童沼澤
- 新地圖：河童沼澤（拉下三個拉桿打開水門）、水神祠 B1（拉桿＋推石頭＋裂牆）、水神祠 B2（燈籠順序「水→木→稻」、水虎守衛寶箱）、河童王的水殿
- 新怪物：河童（衝撞）、泥田坊（丟泥巴，被打中會變慢）、青鬼火（會毒）、水虎（精英）
- Boss 河童王：水砲、拍擊 → 召喚河童、扇形水彈 → 狂暴、橫掃一整排的大浪；打開四角的水閘讓頭上的皿乾掉（硬直 4 秒、傷害 ×1.5）
- 夜叉丸首次登場；打倒河童王後選「解開詛咒」或「討伐」（羈絆值／怒火值）
- 等級上限提高到 Lv20；Lv6、Lv9 各學會一個新技能；選單「技能」分頁可以選要裝在技能鈕上的 2 個技能
- 轉職（Lv10＋第一章結束，找宮司爺爺）：劍聖／鬼武者、獵妖師／風隼、大陰陽師／式神使，屬性 +10%、各 2 個新技能
- 第三階裝備 8 件、鍛冶屋新配方 2 張、支線「河太郎的皿」、告示板新委託與懸賞、新素材（河童的皿碎片、泥塊）
- 新背景音樂「河童沼澤」

**鍛冶屋、聲音與平衡（M7）**
- 完成鐵心的支線後開放鍛冶屋：打造（6 張配方，用怪物素材）、強化（最多 +5，每級基礎能力 +8%，消耗玉鋼）、合成（3 件同稀有度 → 1 件高一級）
- 音樂與音效全部以 Web Audio 即時合成：4 首原創背景音樂（狐火村、迷霧竹林、古井地城、土蜘蛛），20 多種音效
- 選單「設定」分頁：音樂、音效音量、觸控按鈕透明度、調降難度（設定存在這台裝置）
- 數值平衡：不刻意練功的話，打 Boss 時約 Lv6，打完約 Lv7（符合 PRD 5.1 的 Lv7–9）
- 素材來源見 [CREDITS.md](CREDITS.md)

**任務（M5）**
- 支線任務 3 個：太郎的獨角仙、阿梅的護身符、鐵心的玉鋼（頭上有「！」的 NPC 有任務，「？」表示可以交付）
- 神社前的告示板：討伐任務（狐火、骨蜘蛛）、收集任務（野狐的毛、唐傘的破布）、每日懸賞（依裝置日期每天換 3 個）
- 怪物會掉素材（狐火的殘焰、唐傘的破布、野狐的毛、蜘蛛絲、玉鋼），收集任務會在交付時收走
- 任務物品（獨角仙、護身符）接了任務才會出現在竹林
- 選單「任務」分頁：主線目標、進行中的任務與進度、已完成；畫面上方顯示追蹤中的任務

**Boss 與存檔（M6）**
- 土蜘蛛三階段：揮擊與直線吐絲 → 召喚骨蜘蛛與毒池 → 狂暴（快 30%）、衝撞、蛛網封路；每招都有預兆
- 點亮場地四角的石燈籠：燒斷蛛網、土蜘蛛硬直 3 秒，硬直中傷害 ×1.5
- 畫面上方的 Boss 血條標出換階段的位置
- 對話選項會影響羈絆值／怒火值（第四章的結局用）；打倒土蜘蛛後選「淨化」或「斬除」
- 存檔：地藏石像（狐火村、B1、B3）補滿 HP／MP 並可存到 3 個欄位；每次換地圖自動存檔；標題畫面可以「繼續遊戲」或「讀取存檔」
- 存檔在瀏覽器的 localStorage；無痕模式或封鎖網站資料時會存不了，畫面會提示

**探險（M4）**
- 古井地城三層，地城很暗，火把與主角身上有光
- 謎題：推石塊到踏板開門（B1 一顆、B3 兩顆，石塊上了踏板就卡住）、照壁畫順序點亮石燈籠（B2，點錯會全部熄滅）
- 裂開的牆打得破，後面有密室；狐火會提示竹林的密道
- 鐵箱要用「銅鑰匙」；提燈鬼（精英）守著的金箱要打倒它才能開
- 新怪物：骨蜘蛛（保持距離、閃紫光後吐毒絲）、提燈鬼（地上出現紅圈後重擊）
- 右上角小地圖（寶箱、出入口、妖怪、門），選單「收集」分頁顯示各區域寶箱與隱藏地點的收集度
- `tests/maps.test.ts` 自動檢查每張地圖：寶箱、出口都走得到，推石塊的路線可以推到踏板

**成長與裝備（M3）**
- 等級與經驗：升級所需 `floor(20 × L^1.6)`，第一版上限 Lv10，升級時 HP／MP 全滿，依職業成長
- 6 個裝備欄位（武器、頭、身、手、腳、飾品），23 種裝備，武器分職業
- 5 種稀有度（普通／優良／稀有／史詩／傳說），隨機詞條；打怪 10% 掉裝備，部分寶箱開出裝備
- 背包 30 格（消耗品每 99 個一格），可買「擴充布袋」到 60 格
- 選單（右上角）：狀態、裝備（換上前會顯示能力增減）、背包（使用道具、丟掉裝備）
- 道具屋「鈴屋」：和阿鈴對話後可以買道具與普通裝備、賣東西（原價 40%）

**戰鬥（M2）**
- 三個職業：劍士（近戰三段斬）、弓術師（射箭，長按蓄力射出貫穿箭）、陰陽師（丟符咒）
- 攻擊與技能會自動瞄準最近的敵人，目標腳下有紅圈
- 每個職業 2 個技能（耗 MP、有冷卻）：迴旋斬／突刺、三連矢／定身箭、火符／結界
- 閃避翻滾（前 0.25 秒無敵）、受傷無敵 0.9 秒與擊退
- 狀態異常：燒傷、中毒、麻痺；快捷「藥」鈕會自動選最適合的道具
- 竹林怪物：狐火、唐傘小僧、野狐；三種難度；力盡後回到最後進入的地圖入口，道具保留
- 村子西邊有打不壞的練習用稻草人

**探索與劇情**
- 10 張地圖、6 位 NPC（對話依劇情進度改變）、14 個寶箱、4 個隱藏地點
- 之後：正式美術素材、數值平衡

## 結構

```
src/
  main.ts          Phaser 設定
  config.ts        解析度、速度、場景名稱
  scenes/          Boot、Title、World、UI
  entities/        Player、Enemy（AI）、Boss（土蜘蛛）、KappaKing（河童王）、Daitengu（大天狗）、OmniBoss（酒吞童子、百鬼之主）
  combat/          CombatSystem（攻擊、技能、閃避、受傷）、特效
  audio/           音樂曲譜與 Web Audio 合成器
  systems/         純邏輯（combat、progression、equipment、inventory、collection、save、quests、forge、settings、boss、movement、dialogue、gameState、interaction），有單元測試
  data/            職業、轉職、技能、怪物、裝備、配方、商店、任務、對話、NPC、地圖清單
  ui/              VirtualJoystick、TouchButton、DialogueBox、camera 工具
  ui/dom/          選單與商店（HTML 疊加層）
assets/            佔位素材（由 scripts/gen-placeholder-assets.mjs 產生）
scripts/           素材產生器、Artifact 打包
tests/             Vitest
```
