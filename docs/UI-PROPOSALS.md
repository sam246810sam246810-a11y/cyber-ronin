# 介面精緻化建議（2026-11-15）

> 目標：從「能用」變成「像上架手遊一樣精緻」。可以分批做，每一項都標了效果、工程量（S＝半天內、M＝1～2 天、L＝3 天以上）和美術點數。
> 參考的是精緻手遊常見的介面做法（底部分頁列、頂部資源列、大顆主按鈕、紅點提示），不照抄任何特定遊戲的版面或美術，風格維持我們自己的賽博龐克霓虹風。

## A. 版面結構（不需要美術，效果最大）

### A1. 底部分頁列 ★推薦
- 固定在底部的 5 個分頁：**強化｜義體｜出擊（大廳，置中放大）｜抽卡｜任務**
- 每個分頁有圖示（用現有的技能圖示或之後生成的專用圖示），選中的分頁會浮起、發光
- 分頁上有紅點（可領獎勵、可強化、免費抽等）
- 圖鑑、設定移到大廳側邊
- **工程量** M｜**美術** 0（之後可換成 B1 生成的圖示）

### A2. 頂部資源列 ★推薦
- 左：玩家資訊（目前角色頭像＋最佳通緝等級）
- 右：**晶片、信用點、零件**三個資源膠囊，各有圖示與「+」（點了跳到抽卡或商店）
- 數字變動時會跳動
- **工程量** S｜**美術** 資源圖示 3 個，約 1 點（或用現有掉落物圖示）

### A3. 大廳「出擊卡」 ★推薦
- 大廳中間放一張大卡片：地圖插圖（霓虹貧民窟）、地圖名稱、最佳紀錄、通緝等級 ± 選擇
- 卡片下方一顆**大型發光的「出擊」按鈕**（有呼吸光暈）
- 角色放大站在卡片上方，左右箭頭直接切換角色（把角色選擇頁併進大廳）
- **工程量** M｜**美術** 地圖插圖 1 張，約 1 點

### A4. 側邊浮動功能鈕
- 大廳左右兩側的小圓鈕：**每日挑戰、成就、圖鑑、設定**，有紅點與小標籤
- **工程量** S｜**美術** 0～1 點

### A5. 設定視窗
- 齒輪按鈕打開：音樂、音效（滑桿調音量）、震動、特效等級、傷害數字開關
- **工程量** S｜**美術** 0

## B. 視覺風格

### B1. 生成整套 UI 素材 ★推薦（需要點數）
- 用 Higgsfield 生成：主要／次要按鈕底圖、面板框、分頁圖示 5 個、資源圖示 3 個、紅點徽章、彈窗外框
- 做成可伸縮的「九宮格」素材，任何大小的按鈕都能用
- 照你的流程，先做模型比較再整批生成
- **工程量** M｜**美術** 比較約 16 點＋正式約 6 點

### B2. 程式畫的精緻按鈕（不需要點數）
- 按鈕改成：漸層底色、上緣高光、下緣陰影、霓虹外發光、按下時下沉
- 主要按鈕（出擊、領取）用亮色實心，次要按鈕用半透明，危險操作用紅色
- 可以先做 B2 立刻改善，之後再用 B1 的素材替換
- **工程量** S～M｜**美術** 0

### B3. 遊戲標誌（Logo）
- 生成「CYBER RONIN」霓虹招牌風格的標誌圖，中文「賽博浪人」用字型疊上（AI 畫中文字容易出錯）
- **工程量** S｜**美術** 比較約 8 點＋正式約 1 點

### B4. 大廳背景插畫
- 生成一張直式的霓虹街景（雨夜、遠方高樓、招牌），取代現在重複的地面
- 加上雨滴、霓虹閃爍、遠景緩慢移動
- **工程量** S～M｜**美術** 約 1～2 點

### B5. 標題文字特效
- 標題與重要數字加上：雙層描邊、漸層填色、投影，不再只是平面文字
- **工程量** S｜**美術** 0

## C. 動態與回饋

### C1. 轉場與按鈕動畫
- 切換分頁時滑入／淡入；按鈕按下有彈性縮放；彈窗由小放大出現
- **工程量** S

### C2. 獎勵彈窗
- 領取獎勵、抽到稀有物品時：放射光芒＋物品飛向資源列，數字跳動
- **工程量** M

### C3. 大廳角色互動
- 角色更大、腳下有光圈；點角色會做出攻擊動作
- **工程量** S

## D. 各畫面精修（之後逐頁做）

| 畫面 | 改法 |
|---|---|
| 義體 | 角色站在中間，三個裝備欄圍繞在旁邊；下方背包用分頁卡片 |
| 抽卡 | 全螢幕演出：機器亮燈、膠囊彈出、依稀有度出現不同顏色光柱 |
| 結算 | 評價星級＋獎勵逐一飛入、數字跳動 |
| 升級卡 | 卡片翻轉入場、傳說卡金色光柱 |
| 強化商店 | 改成天賦樹或卡片網格，有升級動畫 |

## 我的推薦順序

1. **第一步（不花點數，馬上有感）**：A1 底部分頁列＋A2 頂部資源列＋A5 設定視窗＋B2 程式畫的精緻按鈕＋B5 標題特效＋C1 轉場
2. **第二步（花點數做美術）**：先生成 2～3 張「大廳介面概念圖」給你選方向（約 2～6 點），再做 B1 UI 素材＋B3 標誌＋B4 大廳背景＋A3 出擊卡
3. **第三步**：C2 獎勵彈窗＋C3 角色互動＋D 各畫面逐頁精修
