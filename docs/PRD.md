# 《坩堝花園》PRD v0.3（MVP 試作：稀有度＋角色版）

> v0.2：藥水不再投擲，改成「煉成即喝下、本局永久強化角色」，新增裂變。
> v0.3：元素擴充為 5 種、素材 / 藥水 / 突變卡 / 角色全部分稀有度、新增 4 名角色與解鎖條件、移除復活（不死鳥之淚改為烈焰之心）。

## 0. 已定案的決策

| 項目 | 決定 |
|---|---|
| 技術 / 平台 | Phaser 3 + TypeScript + Vite，手機瀏覽器 / PWA |
| 攻擊 | 基礎攻擊自動瞄準最近敵人 |
| 關卡 | 單一溫室場地，10 波 + Boss，8～12 分鐘 |
| 元素 | 5 種：果凍、冰晶、孢子、火焰花、雷菇 |
| 素材 | 每個元素 4 種素材＝普通 / 稀有 / 史詩 / 傳說，共 20 種 |
| 坩堝 | 3 格，放滿後手動煉成即喝下；點槽位丟棄 |
| 藥水 | 35 種組合依「純色 / 雙色 / 三色」規則生成；品質由素材稀有度決定 |
| 裂變 | 煉成時機率裂變成「神話」藥水（4 種），素材越稀有機率越高 |
| 突變卡 | 每清一波三選一，每張擲稀有度，越稀有數值越高 |
| 角色 | 4 名（普通 / 稀有 / 史詩 / 傳說），各有能力值與被動，達成條件解鎖 |
| 平衡 | 不提供任何復活效果 |
| 美術 | 目前幾何佔位，第二階段接 Higgsfield 素材 |

## 1. 一句話概念
在失控的植物溫室中撿拾藥材、丟進三格坩堝摸索配方，
把藥水喝下去讓自己越來越強、偶爾裂變出傳說藥水，清掉一波波怪物的 9:16 直向肉鴿手遊。

## 2. 目標與非目標
### 目標（MVP 要驗證的事）
- 手機雙拇指操作是否順手
- 「撿藥材 → 湊 3 格 → 煉成喝下 → 變強」的循環是否好玩、成長感是否明顯
- 裂變的驚喜感與傳說藥水的強度是否恰當
- 「自己試出配方」的探索感是否成立
- 突變卡疊加是否帶來 build 變化感

### 非目標（這版不做）
- 正式美術、音樂音效、局外成長、商城、多語系、帳號系統

## 3. 平台與技術規格
- 引擎：Phaser 3 + TypeScript + Vite
- 平台：手機瀏覽器（iOS Safari / Android Chrome），可加入主畫面（PWA manifest）
- 邏輯解析度：720×1280（9:16），等比縮放加黑邊（Phaser Scale.FIT）
- 禁止頁面捲動、雙擊縮放、長按選取；支援多點觸控
- 效能：中階手機 60fps，同屏敵人 ≥ 40、投擲物/特效 ≥ 60
- 存檔：只用 localStorage 保存圖鑑解鎖狀態（讀寫需 try/catch）

## 4. 畫面配置（9:16）
```
┌──────────────────────┐
│ ♥♥♥♥♥   第 3/10 波   02:14 │ ← 頂部 HUD（右上角：暫停、圖鑑）
│                      │
│                      │
│      溫室戰鬥區（約 68%）     │
│                      │
│                      │
├──────────────────────┤
│ [槽1][槽2][槽3] [煉成] │ 🧪手上藥水 │ ← 坩堝列
├──────────────────────┤
│  ( 搖桿 )        [衝刺]     │
│                [投擲]     │ ← 拇指操作區
└──────────────────────┘
```
- 左下：浮動虛擬搖桿（在左半區任意處按下即出現）
- 右下：衝刺鍵（冷卻圓環）、投擲鍵（無藥水時變灰）
- 坩堝列：點槽位丟棄該格；3 格滿時「煉成」鍵發亮
- 藥水架：一次只能拿 1 瓶；手上已有藥水時「煉成」鍵鎖定

## 5. 核心循環
1. 移動、衝刺閃避敵人的預警攻擊；基礎攻擊自動打最近敵人
2. 敵人死亡掉落藥材 → 走過去自動撿取
3. 坩堝 3 格未滿 → 放入下一個空格；已滿 → 藥材留在地上（閃爍提示）
4. 3 格滿 → 按「煉成」（坩堝列或右下拇指鍵）→ 立刻喝下
   - 15% 機率「裂變」成傳說藥水（全螢幕閃光提示）
   - 未知配方首次煉出時寫入圖鑑
5. 喝下的效果整局永久有效：屬性數值成長 + 獲得 / 疊加該藥水的被動
6. 清完一波 → 暫停 → 三選一突變卡 → 下一波
7. 第 10 波後 Boss 戰 → 勝利或死亡 → 結算畫面

## 6. 系統規格

### 6.0 稀有度
| 稀有度 | 顏色 | 倍率 |
|---|---|---|
| 普通 | 灰白 | ×1 |
| 稀有 | 藍 | ×1.5 |
| 史詩 | 紫 | ×2 |
| 傳說 | 金 | ×3 |
| 神話（僅裂變藥水） | 紅 | — |

### 6.1 角色（`data/characters.json`）
| 角色 | 稀有度 | 血 / 攻 / 速 / 射擊間隔 / 衝刺冷卻 | 被動 | 解鎖 |
|---|---|---|---|---|
| 見習煉金師 | 普通 | 5 / 1 / 220 / 0.5 / 1.2 | 坩堝親和：裂變率 +5%、拾取範圍 +20% | 初始 |
| 冰晶射手 | 稀有 | 4 / 0.9 / 235 / 0.38 / 1.1 | 霜冷彈頭：開局帶「冰封」1 層，冰晶素材屬性 +50% | 到達第 5 波 |
| 熔岩重裝 | 史詩 | 8 / 1.6 / 180 / 0.65 / 1.6 | 熔岩護甲：受傷時周圍爆炸，火焰花素材屬性 +50% | 累積裂變 3 次 |
| 雷菇賢者 | 傳說 | 4 / 1 / 215 / 0.45 / 1.2 | 共振：所有藥水被動層數 +25%，開局帶「雷暴之核」1 層 | 擊敗 Boss |

- 解鎖進度存在 localStorage（`crucible-garden.progress.v1`）
- 開始遊戲 → 選角畫面 → 出發；鎖住的角色顯示條件與進度

| 冰晶 I | 冰晶草 | 霜鈴花 | 永凍晶簇 | 極光冰心 | 攻擊間隔 ×0.95、命中減速 +4% |
| 孢子 S | 毒孢子 | 紫斑孢囊 | 腐沼菌冠 | 冥孢之心 | 命中附毒每秒 +0.25 |

| 雷菇 T | 雷菇 | 電光蕈 | 雷鳴菌傘 | 天雷菌核 | 暴擊率 +3%（暴擊 ×2） |

- 一個素材給的「份數」＝稀有度倍率（傳說素材一個＝3 份）
- 掉落：一般敵人 40%（豐收卡可加），精英必掉；元素隨機
- 稀有度權重：一般 80 / 16 / 3.5 / 0.5，每波往高稀有度偏移；精英 30 / 45 / 20 / 5；鑑寶卡提高非普通權重
- 地上素材以光暈顏色表示稀有度，史詩以上掉落時有光柱

### 6.3 藥水（35 種，規則生成）
| 類型 | 組合 | 效果（每瓶，乘上品質倍率） |
|---|---|---|
| 純色 | AAA（5 種） | 核心 A ×2 層 |
| 雙色 | AAB（20 種） | 核心 A ×1 ＋ 附加 B ×1，名稱＝B 形容詞＋A 核心名 |
| 三色 | ABC（10 種） | 附加 A、B、C 各 ×1，傷害 +8% |

**品質**：三個素材稀有度總和 0–1 普通、2–4 稀有、5–7 史詩、8–9 傳說。

| 元素 | 核心被動 | 附加被動 |
|---|---|---|
| 果凍 | 彈力炸彈：子彈彈射 +1/層 | 黏彈：穿透 +1/層 |
| 冰晶 | 霜凍新星：每 6 秒冰環 | 冰封：冰凍率 +6%/層 |
| 孢子 | 瘟疫毒雲：身邊毒霧光環 | 劇毒：附毒 +0.5/秒/層 |
| 火焰花 | 爆炎核心：敵人死亡爆炸 | 灼熱：命中爆炸率 +8%/層 |
| 雷菇 | 雷暴之核：每第 4 發連鎖閃電 | 帶電：命中連鎖率 +8%/層 |

- 被動實作在 `potions/passives.ts`（`core_X` / `rider_X`），三色名稱在 `data/potions.json`

### 6.3.1 裂變與神話藥水（`data/mythics.json`）
- 裂變率＝10% ＋ 每個素材（稀有 +3%、史詩 +6%、傳說 +12%）＋ 裂變催化卡 ＋ 角色加成，上限 65%
- 裂變時素材屬性照拿，被動改為隨機一種神話藥水

| 神話藥水 | 效果 |
|---|---|
| 烈焰之心 | 每 1.5 秒在隨機敵人身上爆炸（疊層加快） |
| 時之砂 | 攻速、衝刺冷卻、所有週期被動加快 25% |
| 世界樹之種 | 每 10 秒大範圍元素綻放（冰凍、毒、擊退） |
| 混沌原液 | 子彈命中小範圍爆炸，傷害 +30% |

### 6.4 敵人（MVP 3 種 + Boss）
| 敵人 | HP | 行為 | 預警 |
|---|---|---|---|
| 藤蔓爬蟲 | 3 | 直線追蹤玩家，接觸傷害 1 | 無 |
| 噴刺花 | 6 | 固定位置，每 3 s 扇形射 5 根刺 | 扇形紅區 0.8 s |
| 跳躍蘑菇 | 8 | 跳向玩家當前位置砸地 | 落點紅圈 1.0 s |
| Boss：食人巨花 | 250 | 三階段輪流：藤蔓衝刺 / 扇形彈幕 / 召喚小怪＋地面砸擊 | 全部有紅區預警 |

### 6.5 波次
- 10 波，每波約 45～60 秒或清完即結束
- 敵人數量與組成由 `data/waves.json` 定義（例：第 1 波只有爬蟲，第 4 波起加噴刺花，第 7 波起加蘑菇）
- 波與波之間 2 秒緩衝 + 突變卡選擇

### 6.6 突變卡（`data/mutations.json`）
- 三選一不重複；每張獨立擲稀有度：基礎 62 / 27 / 9 / 2，每波往高稀有度偏移
- 數值＝普通數值 × 稀有度倍率（例：普通濃縮 +25%、傳說濃縮 +75%），可疊加

| 卡片 | 普通數值 |
|---|---|
| 濃縮 | 素材屬性加成 +25% |
| 擴散 | 被動範圍 +20% |
| 延時 | 週期被動加快 15% |
| 共鳴 | 純色藥水核心額外 +0.5 層 |
| 裂變催化 | 裂變率 +5% |
| 雙倍釀造 | 15% 機率效果兩次 |
| 回春 | 每喝一瓶 20% 機率回 1 血 |
| 豐收 | 掉落率 +8% |
| 鑑寶 | 高稀有度素材機率 +20% |
| 磁吸 | 拾取範圍 +30% |

## 7. 狀態機
### 遊戲流程
```
Boot → Preload → MainMenu ─┬→ CharacterSelect → Run ─→ WaveCombat ⇄ CardSelect ─→ BossFight ─→ Result ─→ MainMenu
                            └→ Codex（圖鑑）
Run 中任何時候可 Pause（含圖鑑查看）
```
### 角色狀態
Idle / Move / Dash（無敵）/ Hurt（受擊無敵）/ Dead

### 坩堝狀態
Empty → Filling(1~2) → Full（可煉成）→ Brewing（0.3 s）→ Empty
（煉成即喝下；點槽位丟棄 → 回到 Filling）

## 9. 驗收標準（MVP 完成定義）
- [ ] iPhone Safari / Android Chrome 直向全螢幕可玩，不會誤觸捲動或縮放
- [ ] 浮動搖桿移動順暢；衝刺有冷卻圓環，衝刺期間不受傷
- [ ] 基礎攻擊自動瞄準最近敵人
- [ ] 3 種敵人 + Boss 都有預警，可靠衝刺閃掉
- [ ] 坩堝 3 格：撿取自動填格、點格丟棄、滿格才能煉成、手上有藥水時不能煉
- [ ] 10 種配方都能煉出並有可辨識的不同效果
- [ ] 首次煉出配方會跳「新發現」，圖鑑更新且重開網頁後仍保留
- [ ] 每波結束三選一，選完立即生效，可疊層，卡面顯示層數
- [ ] 能打完 10 波 + Boss，或死亡後進入結算；單局約 8～12 分鐘
- [ ] 新增藥材 / 配方 / 卡片只需要改 JSON + 新增一個效果或 modifier 檔
- [ ] 提供 debug 面板（開發模式）：跳波、給藥材、直接選卡、解鎖全圖鑑
- [ ] README 附 `npm install && npm run dev`、手機區網測試方式（`--host`）
