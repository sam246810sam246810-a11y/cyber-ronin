## 1. 一句話概念
在失控的植物溫室中撿拾藥材、丟進三格坩堝摸索配方，
把藥水喝下去讓自己越來越強、偶爾裂變出傳說藥水，清掉一波波怪物的 9:16 直向肉鴿手遊。

## 2. 目標與非目標
### 目標（MVP 要驗證的事）
- 手機雙拇指操作是否順手
- 「撿藥材 → 湊 3 格 → 煉成喝下 → 變強」的循環是否好玩、成長感是否明顯
- 裂變的驚喜感與傳說藥水的強度是否恰當
- 「自己試出配方」的探索感是否成立
- 突變卡疊加是否帶來 build 變化感

### 非目標（這版不做）
- 正式美術、音樂音效、局外成長、商城、多語系、帳號系統

## 3. 平台與技術規格
- 引擎：Phaser 3 + TypeScript + Vite
- 平台：手機瀏覽器（iOS Safari / Android Chrome），可加入主畫面（PWA manifest）
- 邏輯解析度：720×1280（9:16），等比縮放加黑邊（Phaser Scale.FIT）
- 禁止頁面捲動、雙擊縮放、長按選取；支援多點觸控
- 效能：中階手機 60fps，同屏敵人 ≥ 40、投擲物/特效 ≥ 60
- 存檔：只用 localStorage 保存圖鑑解鎖狀態（讀寫需 try/catch）

## 4. 畫面配置（16:9 橫向，1280×720）
```
┌──────────────────────────────────────────────────┐
│ ♥♥♥♥♥  [坩堝 ▢▢▢][煉成] [元素累積/裂變率]  溫室 1-2  🪙12  ⏸ │ ← 上方資訊列
├──────────────────────────────────────────────────┤
│ 詞條 / 委託提示                                   [小地圖] │
│                                                  │
│                   戰  場                          (煉成) │
│                                         [換武器]       │
│   ( 搖桿：左半邊任意處 )                    (技能) (衝刺) │
└──────────────────────────────────────────────────┘
```
- 左半邊戰場任意處按下就出現浮動搖桿；右下四顆按鈕弧形排列、半透明疊在戰場上
- 直向持機時顯示「請把手機橫放」

## 5. 核心循環
1. 移動、衝刺閃避敵人的預警攻擊；基礎攻擊自動打最近敵人
2. 敵人死亡掉落藥材 → 走過去自動撿取
3. 坩堝 3 格未滿 → 放入下一個空格；已滿 → 藥材留在地上（閃爍提示）
4. 3 格滿 → 按「煉成」（坩堝列或右下拇指鍵）→ 立刻喝下
   - 15% 機率「裂變」成傳說藥水（全螢幕閃光提示）
   - 未知配方首次煉出時寫入圖鑑
5. 喝下的效果整局永久有效：屬性數值成長 + 獲得 / 疊加該藥水的被動
6. 清完一波 → 暫停 → 三選一突變卡 → 下一波
7. 第 10 波後 Boss 戰 → 勝利或死亡 → 結算畫面

### 6.4 地下城結構
- 3 區（溫室 / 熔岩花園 / 雷雲山頂）× 3 層；每層在 7×7 格子上隨機長出 9～11 間房（區域越後越多）
- 房間以上下左右的門相連；右上角小地圖顯示走過的房間、相鄰房間與特殊房間顏色點，未清空的戰鬥房有紅點
- 走到開著的門就淡出切換到隔壁房間

| 房間 | 說明 |
|---|---|
| 起點 | 安全房 |
| 戰鬥房 | 進門 0.45 秒後關門，兩波敵人清完才開門；清空掉金幣與 50% 素材 |
| 精英挑戰房 | 碰祭壇才開始，敵人預算 ×1.2 且必有精英；勝利給 2 個精英級素材＋保底稀有突變卡 |
| 寶箱房 | 開箱噴 3～4 個精英級素材＋金幣 |
| 商店房 | 固定療傷藥＋2 個隨機商品（史詩素材、傳說素材、保底稀有 / 史詩突變卡），價格隨區域上升 |
| 事件房（60% 出現） | 祈願泉或以物易物商人（用坩堝素材交換） |
| 樓梯房（第 1、2 層） | 最遠的盡頭；走上去先選一張樓層獎勵突變卡，再到下一層 |
| Boss 房（第 3 層） | 最遠的盡頭；擊敗後掉落素材＋保底稀有突變卡，出現樓梯前往下一區（回 3 血） |

- 戰鬥房敵人：依區域敵人池（`data/regions.json` 的 `enemies` 權重與花費）湊滿該層預算；越深的房間預算越高
- 敵人血量倍率＝區域倍率 ×（1 + 0.15 ×（層數 − 1））
- 金幣：一般敵人 35% 掉 1 枚、精英 5 枚、Boss 25 枚；靠近會自動吸過來；「貪婪」突變卡增加掉落

### 6.4.2 時空裂縫
- 每次穿門有 6% 機率改掉進時空裂縫（目標是起點 / 樓梯 / Boss 房時不會觸發）；時間旅商可保證下一次觸發
- 過去（50%）：懷舊配色的溫室，溫室敵人、血量 ×0.8；清空掉 5 個素材＋10 金幣
- 未來（50%）：霓虹配色，下一區的敵人池與預算、血量為下一區 ×1.25（最後一區 ×1.5），必有精英；清空掉傳說素材＋史詩以上武器＋保底史詩突變卡

### 6.5.2 新手引導
- 第一次遊玩時依情境顯示：移動 → 撿素材（箭頭指向）→ 煉成（箭頭指向按鈕）→ 藥水與裂變說明 → 攻擊預警與衝刺 → 開門探索 → 商店 → 樓梯
- 每個提示只出現一次；第一局結束後不再顯示（重置進度可重看）

## 7. 狀態機
