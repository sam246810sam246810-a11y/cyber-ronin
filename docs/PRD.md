# 《坩堝花園》PRD v0.1（MVP 試作）

## 0. 已定案的決策

| 項目 | 決定 |
|---|---|
| 技術 | Phaser 3 + TypeScript + Vite |
| 平台 | 手機瀏覽器 / PWA |
| 攻擊 | 基礎攻擊自動瞄準最近敵人 |
| 關卡 | 單一溫室場地，10 波 + Boss |
| 坩堝 | 3 格，放滿後手動按「煉成」；不滿 3 格不能煉 |
| 藥水 | 煉成後成為「下一發投擲物」 |
| 配方 | 10 種全部獨立；一開始未知，煉過一次才記入圖鑑 |
| 坩堝滿格 | 點槽位即可丟棄該格藥材 |
| 突變卡 | 每清一波三選一；可重複疊加；只強化藥水 |
| 局外成長 | MVP 不做（只保存圖鑑解鎖紀錄） |
| 美術 | 第一階段用幾何色塊佔位，第二階段接 Higgsfield 素材 |
| 單局時長 | 8～12 分鐘 |

---

## 1. 一句話概念
在失控的植物溫室中撿拾藥材、丟進三格坩堝摸索配方，
用不斷突變的藥水清掉一波波怪物的 9:16 直向肉鴿手遊。

## 2. 目標與非目標
### 目標（MVP 要驗證的事）
- 手機雙拇指操作是否順手
- 「撿藥材 → 湊 3 格 → 煉成 → 投擲」的循環是否好玩、節奏是否卡手
- 「自己試出配方」的探索感是否成立
- 突變卡疊加是否帶來 build 變化感

### 非目標（這版不做）
- 正式美術、音樂音效、局外成長、商城、多語系、帳號系統

## 3. 平台與技術規格
- 引擎：Phaser 3 + TypeScript + Vite
- 平台：手機瀏覽器（iOS Safari / Android Chrome），可加入主畫面（PWA manifest）
- 邏輯解析度：720×1280（9:16），等比縮放加黑邊（Phaser Scale.FIT）
- 禁止頁面捲動、雙擊縮放、長按選取；支援多點觸控
- 效能：中階手機 60fps，同屏敵人 ≥ 40、投擲物/特效 ≥ 60
- 存檔：只用 localStorage 保存圖鑑解鎖狀態（讀寫需 try/catch）

## 4. 畫面配置（9:16）
```
┌──────────────────────┐
│ ♥♥♥♥♥   第 3/10 波   02:14 │ ← 頂部 HUD（右上角：暫停、圖鑑）
│                      │
│                      │
│      溫室戰鬥區（約 68%）     │
│                      │
│                      │
├──────────────────────┤
│ [槽1][槽2][槽3] [煉成] │ 🧪手上藥水 │ ← 坩堝列
├──────────────────────┤
│  ( 搖桿 )        [衝刺]     │
│                [投擲]     │ ← 拇指操作區
└──────────────────────┘
```
- 左下：浮動虛擬搖桿（在左半區任意處按下即出現）
- 右下：衝刺鍵（冷卻圓環）、投擲鍵（無藥水時變灰）
- 坩堝列：點槽位丟棄該格；3 格滿時「煉成」鍵發亮
- 藥水架：一次只能拿 1 瓶；手上已有藥水時「煉成」鍵鎖定

## 5. 核心循環
1. 移動、衝刺閃避敵人的預警攻擊；基礎攻擊自動打最近敵人
2. 敵人死亡掉落藥材 → 走過去自動撿取
3. 坩堝 3 格未滿 → 放入下一個空格；已滿 → 藥材留在地上（閃爍提示）
4. 3 格滿 → 按「煉成」→ 依組合產出藥水，未知配方首次煉出時跳出「新發現！」並寫入圖鑑
5. 按「投擲」→ 藥水朝最近敵人（或搖桿方向，無敵人時）拋出
6. 清完一波 → 暫停 → 三選一突變卡 → 下一波
7. 第 10 波後 Boss 戰 → 勝利或死亡 → 結算畫面（存活時間、擊殺數、本局新發現配方）

## 6. 系統規格

### 6.1 角色
| 參數 | 初始值 |
|---|---|
| HP | 5（愛心顯示） |
| 移速 | 220 px/s |
| 衝刺距離 / 時間 | 160 px / 0.15 s |
| 衝刺無敵幀 | 0.25 s |
| 衝刺冷卻 | 1.2 s |
| 受擊無敵 | 0.6 s（閃爍） |
| 基礎攻擊 | 自動瞄準，種子彈每 0.5 s 一發，傷害 1 |
| 拾取半徑 | 48 px |

### 6.2 藥材（3 種）
| 代號 | 藥材 | 屬性 | 佔位顏色 | 掉落權重 |
|---|---|---|---|---|
| J | 果凍核 | 黏 / 彈 | 粉紅 #ff7eb6 | 1 |
| I | 冰晶草 | 冰 / 緩速 | 淺藍 #7ed4ff | 1 |
| S | 毒孢子 | 毒 / 持續傷害 | 綠 #7eff8a | 1 |

- 每隻敵人 40% 機率掉 1 個藥材；精英 100%
- 地上藥材 12 秒後消失（最後 3 秒閃爍）

### 6.3 配方（10 種，不計順序）
| 組合 | 藥水 | 效果（基礎值） |
|---|---|---|
| JJJ | 彈力炸彈 | 落地彈跳 4 次，每次半徑 60 範圍傷害 3 |
| III | 霜凍新星 | 半徑 140 冰凍 1.5 s，傷害 2 |
| SSS | 瘟疫毒雲 | 留下半徑 110 毒霧 5 s，每 0.5 s 傷害 1 |
| JJI | 冰膠陷阱 | 留下黏液區 4 s，敵人減速 60% |
| JJS | 爆裂菌囊 | 命中爆炸傷害 3，分裂成 4 個小毒囊（各 1.5） |
| IIJ | 冰晶彈珠 | 在敵人間彈射 5 次，每次傷害 2 + 減速 |
| IIS | 腐霜 | 冰凍 1.2 s，解凍時引爆毒傷 4 |
| SSJ | 黏毒沼澤 | 毒沼 4 s，把範圍內敵人往中心拉 |
| SSI | 冰毒針雨 | 落點向外射出 12 根針，各傷害 1.5 + 毒 |
| JIS | 元素綻放 | 大爆炸半徑 160，傷害 6，附加三種屬性 |

- 配方用 `data/recipes.json` 定義：key 為排序後的組合字串（如 `"IJS"`），value 為藥水 id 與參數
- 每種藥水的行為寫成一個效果函式，透過 registry 對應，不要用一大串 if/else
- 圖鑑：10 格，未發現的顯示「？」與已知的屬性提示（例如「？＋冰＋冰」不揭露）

### 6.4 敵人（MVP 3 種 + Boss）
| 敵人 | HP | 行為 | 預警 |
|---|---|---|---|
| 藤蔓爬蟲 | 3 | 直線追蹤玩家，接觸傷害 1 | 無 |
| 噴刺花 | 6 | 固定位置，每 3 s 扇形射 5 根刺 | 扇形紅區 0.8 s |
| 跳躍蘑菇 | 8 | 跳向玩家當前位置砸地 | 落點紅圈 1.0 s |
| Boss：食人巨花 | 250 | 三階段輪流：藤蔓衝刺 / 扇形彈幕 / 召喚小怪＋地面砸擊 | 全部有紅區預警 |

### 6.5 波次
- 10 波，每波約 45～60 秒或清完即結束
- 敵人數量與組成由 `data/waves.json` 定義（例：第 1 波只有爬蟲，第 4 波起加噴刺花，第 7 波起加蘑菇）
- 波與波之間 2 秒緩衝 + 突變卡選擇

### 6.6 突變卡（只強化藥水，可疊層）
| 卡片 | 每層效果 |
|---|---|
| 彈跳 | 藥水落地後多彈跳 1 次 |
| 分裂 | 爆炸後分出 2 個小藥水（50% 威力） |
| 擴散 | 範圍 +25% |
| 延時 | 場地類效果持續 +1 s |
| 連投 | 一次多投 1 發，每發傷害 ×0.75 |
| 穿透 | 飛行途中穿過 1 個敵人並造成傷害 |
| 濃縮 | 藥水傷害 +20% |
| 雙倍釀造 | 煉成時 +20% 機率得到 2 瓶（藥水架上限暫時 +1） |
| 共鳴 | 同屬性 3 格配方（JJJ/III/SSS）效果 +35% |

- 實作為 Modifier：`apply(potionParams, stacks) => potionParams` 與可選的行為 hook（onLand / onHit / onExpire）
- 三選一不出現重複卡；卡面顯示目前層數

## 7. 狀態機
### 遊戲流程
```
Boot → Preload → MainMenu ─┬→ Run ─→ WaveCombat ⇄ CardSelect ─→ BossFight ─→ Result ─→ MainMenu
                            └→ Codex（圖鑑）
Run 中任何時候可 Pause（含圖鑑查看）
```
### 角色狀態
Idle / Move / Dash（無敵）/ Hurt（受擊無敵）/ Dead

### 坩堝狀態
Empty → Filling(1~2) → Full（可煉成）→ Brewing（0.3 s 動畫）→ Empty
（手上有藥水時 Full 不可煉成；點槽位丟棄 → 回到 Filling）

## 9. 驗收標準（MVP 完成定義）
- [ ] iPhone Safari / Android Chrome 直向全螢幕可玩，不會誤觸捲動或縮放
- [ ] 浮動搖桿移動順暢；衝刺有冷卻圓環，衝刺期間不受傷
- [ ] 基礎攻擊自動瞄準最近敵人
- [ ] 3 種敵人 + Boss 都有預警，可靠衝刺閃掉
- [ ] 坩堝 3 格：撿取自動填格、點格丟棄、滿格才能煉成、手上有藥水時不能煉
- [ ] 10 種配方都能煉出並有可辨識的不同效果
- [ ] 首次煉出配方會跳「新發現」，圖鑑更新且重開網頁後仍保留
- [ ] 每波結束三選一，選完立即生效，可疊層，卡面顯示層數
- [ ] 能打完 10 波 + Boss，或死亡後進入結算；單局約 8～12 分鐘
- [ ] 新增藥材 / 配方 / 卡片只需要改 JSON + 新增一個效果或 modifier 檔
- [ ] 提供 debug 面板（開發模式）：跳波、給藥材、直接選卡、解鎖全圖鑑
- [ ] README 附 `npm install && npm run dev`、手機區網測試方式（`--host`）
