| 項目 | 內容 |
|---|---|
| 類型 | 直式單指・**動物車隊**自動戰鬥・分岔地圖 Roguelike + 村莊 / 裝備養成 |
| 題材 | 可愛動物：柴犬隊長帶著救來的夥伴，排成一列出征 |

## 1. 與既有產品的差異

| 面向 | 常見同類（走停射擊） | 本作 |
|---|---|---|
| 操作 | 移動時不攻擊、停下才射擊 | **隊伍永遠在前進**，手指只負責轉向；攻擊全自動 |
| 角色 | 單一英雄 | **最多 7 隻動物排成一列**，各有武器與血量；隊伍越長火力越強、也越難閃 |
| 失敗壓力 | 只有一條血 | 夥伴會倒下脫隊（營火可救回），隊長倒下才失敗 |
| 肉鴿選擇 | 技能三選一 | **招募誰、幫誰升星、全隊強化、合體技**，打造自己的隊伍 |
| 關卡 | 線性房間 | **分岔地圖**：戰鬥 / 菁英 / 救援 / 營火 / 寶箱 / 行商，自己規劃路線 |
| 局外 | 裝備 + 天賦 | 裝備 + **動物村莊**（蓋房子解鎖夥伴與永久加成） |

## 2. 核心循環

```
30 秒   轉向閃避 → 夥伴自動攻擊 → 撿經驗與金幣 → 升級三選一
1 層    在地圖上選下一個節點：戰鬥、救援、營火、寶箱、行商、菁英
1 局    9 層地圖（約 5～8 分鐘），第 8 層營火、第 9 層 Boss
1 天    帶回金幣與裝備 → 強化裝備、蓋村莊 → 隊伍更強 → 走得更遠
7 天    嘉年華任務 → 積分 → 傳說魔杖
```

## 3. 戰鬥

### 3.1 操作
- 按住任意處出現浮動搖桿，往哪拉隊伍就轉向哪（有轉向速度限制，像開車）。
- 放開手指時隊伍維持方向前進，碰到邊界會反彈。
- 桌機支援 WASD / 方向鍵。

### 3.2 隊伍
- 隊員沿隊長走過的軌跡跟隨，間距固定。
- 每位隊員有獨立血量；敵人會攻擊**最靠近的隊員**。
- 隊員倒下會脫隊，該場戰鬥不再攻擊；營火、野餐便當、復活可救回。
- 隊長倒下 → 可看廣告 / 💎30 復活一次（隊長滿血、倒下的夥伴 50% 回歸）。

### 3.3 夥伴（`src/data/partners.ts`）

| 夥伴 | 定位 | 武器 | 解鎖 |
|---|---|---|---|
| 🐶 柴犬隊長 | 隊長 | 星星彈；3 星 2 發、5 星 3 發 | 預設 |
| 🐱 火球貓咪 | 輸出 | 火球範圍爆炸 + 燃燒 | 預設 |
| 🐰 連射兔兔 | 輸出 | 高速連射紅蘿蔔 | 預設 |
| 🐻 抱抱熊 | 坦克 | 生命 ×2.4，定期震地擊退周圍 | 預設 |
| 🦊 閃電狐狸 | 控場 | 閃電連鎖 3～5 個目標 | 村莊招募所 Lv1 |
| 🐧 雪球企鵝 | 控場 | 雪球範圍傷害 + 減速 | 招募所 Lv2 |
| 🐹 護理倉鼠 | 治療 | 定期治療血量最低的隊友 | 招募所 Lv3 |

升星（1～5 星）：每星傷害 +35%、生命 +25%，3 星起武器強化。

### 3.4 三選一卡片（`src/data/skills.ts`）

| 類別 | 內容 |
|---|---|
| 新夥伴 | 招募一隻尚未在隊伍中的已解鎖夥伴（隊伍少於 3 隻時權重較高） |
| 升星 | 指定夥伴 +1 星並回滿血 |
| 全隊強化 | 團隊特訓、興奮點心、輕快腳步、大胃王、野餐便當、吸吸磁鐵、幸運四葉草、致命爪擊、吃飽飽 |
| **合體技（金卡）** | 火狐流星（貓 3 星 + 狐）、暴雪兔兔（兔 3 星 + 企鵝）、熊熊守護（熊 3 星 + 倉鼠）、團結之星（隊長 3 星 + 隊伍 4 隻以上） |

每局重抽次數 = 1 + 村莊瞭望塔等級（每次需看廣告，模擬）。

### 3.5 敵人與 Boss
沿用 v0.1：追擊、射手、衝刺、環形彈、跳躍等 8 種一般怪，2 種菁英（召喚、螺旋彈幕），2 種 Boss（50% 血進入二階段）。敵人鎖定最近的隊員。

### 3.6 戰鬥節點
- 一般戰鬥：2～3 波，場上剩 1 隻或 14 秒後下一波。
- 菁英：一波小怪 + 菁英，必掉一件裝備。
- Boss：章節頭目。

## 4. 分岔地圖（`src/data/chapters.ts`）

- 9 層：第 1 層戰鬥、第 2 層含救援、第 3～7 層隨機、第 8 層營火、第 9 層 Boss。
- 每層 2～3 個節點，連到下一層相鄰的 1～2 個節點。

| 節點 | 內容 |
|---|---|
| ⚔️ 戰鬥 | 經驗、金幣 |
| 💀 菁英 | 較難，必掉裝備（第 4 層起出現） |
| 🐾 救援 | 二選一新夥伴（隊伍滿則改為升星） |
| 🏕️ 營火 | 全隊回 50% 並救回倒下夥伴，或讓一位夥伴升星 |
| 🎁 寶箱 | 金幣 + 免費三選一 |
| 🛒 行商 | 花本局金幣買便當、招募券、升星糖果、技能卡包；花掉的金幣不會帶回家 |

| 章節 | 敵人血量 | 傷害 | 推薦戰力 |
|---|---|---|---|
| 1 陽光草原 | ×1 | ×1 | 1,200 |
| 2 椰子海灘 | ×2.4 | ×1.6 | 2,600 |
| 3 棉花糖雪山 | ×5.2 | ×2.5 | 5,000 |

每層敵人血量 +12～14%，傷害 +5%。

## 6. 局外養成

### 6.1 裝備（`src/data/equipment.ts`）
隊長的四件裝備（武器、護甲、戒指、項圈）強化整支隊伍。六階品質、三合一、強化、一鍵合成，同 v0.1。

### 6.2 夥伴永久等級（碎片）
- 7 種夥伴各有永久等級 Lv1～10，每級讓牠在冒險中的傷害與生命 +10%。
- 升級消耗碎片（10 / 20 / 35 / 55 / 80 / 110 / 150 / 200 / 260）與金幣（250 × 等級²）。
- 碎片來源：每場戰鬥 1 片、菁英 4 片、寶箱節點 3 片、Boss 10 片（給隊伍中隨機一位）；夥伴蛋；每日免費蛋。
- 尚未在村莊解鎖的夥伴可以先累積碎片。
- **夥伴蛋**：💎200，抽 3 次，每次 5 片隨機夥伴碎片（7 種各 1/7，公開機率）；每天可看廣告免費孵 1 顆。

### 6.3 動物村莊（`src/data/village.ts`）

| 建築 | 效果 | 上限 |
|---|---|---|
| 🏟️ 訓練場 | 全隊攻擊 +6% / 級 | 10 |
| 🏥 醫療小屋 | 全隊生命 +7% / 級 | 10 |
| 🏡 招募所 | Lv1 狐狸、Lv2 企鵝、Lv3 倉鼠、Lv4 出發自帶夥伴、Lv5～6 自帶夥伴 2～3 星 | 6 |
| 🌾 金幣糧倉 | 冒險金幣 +10% / 級 | 8 |
| 🗼 瞭望塔 | 每局重抽 +1 / 級 | 3 |

- 一位建築師，一次只能蓋一棟。
- 費用 = 基礎 × 1.65^等級；時間 = 20 秒 × (等級+1)^1.6（Lv1 20 秒、Lv10 約 15 分鐘）。
- 加速：看廣告 -5 分鐘（每次建造一次）、或鑽石立即完成（每分鐘 3 💎）。

## 7. 商業化（模擬）

| 模組 | 內容 |
|---|---|
| 突破禮包 NT$30 | 失敗且（Boss 剩 ≤50% 或已到第 7 層以上）時彈出；1 小時限時、限購 1、冷卻 24h |
| 建造加速 | 鑽石秒蓋；廣告加速 5 分鐘 |
| 首儲禮 | 首次任何購買送史詩月光戒 |
| 鑽石包首購雙倍 | 每檔各一次 |
| 黃金寶箱 | 💎300；稀有 70% / 史詩 25% / 傳說 5%；10 抽保底傳說 |
| 每日免費 | 木箱 1 次、看廣告領鑽 3 次 |
| 夥伴蛋 | 💎200 抽 3 份碎片；每日看廣告免費 1 顆 |
| 復活 | 看廣告或 💎30，每局 1 次 |
| 重抽 | 看廣告，次數由瞭望塔決定 |
| 嘉年華加速包 NT$60 | +40 積分 + 💎300，每日 1 次 |

### 合規原則
1. 禮包價值只用商店實際售價對比，不用虛構原價。
2. 嘉年華免費總積分 325 > 最終大獎門檻 220。
3. 寶箱公開機率與保底。
4. 限時是真的限時。

28 個任務、免費積分 325；新增「村莊建造」「招募夥伴」「合體技」相關任務，引導玩家接觸新系統。

## 8.5 體驗與系統

| 功能 | 說明 |
|---|---|
| 冒險存檔 | 每次回到地圖時自動存檔；重開遊戲後大廳顯示「繼續冒險」。戰鬥中關閉會回到進入該節點前 |
| 新手引導 | 第一次戰鬥顯示拖曳轉向提示（拖曳 1.2 秒後消失）；第一次看地圖、第一次升級各有提示 |
| 背景音樂 | WebAudio 即時合成：大廳 92 BPM、戰鬥 138 BPM（I–V–vi–IV），可在設定單獨關閉 |
| 操作選項 | 放開手指時「繼續前進」（預設）或「停下」 |
