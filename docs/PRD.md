# Cyber Ronin — 產品需求文件（PRD）v1.0

> 狀態：**v1.4**（2026-11-15）。之後如果要修改，請在文末「變更紀錄」寫下版本與原因。

## 1. 產品概述

| 項目 | 內容 |
|---|---|
| 名稱 | Cyber Ronin（賽博浪人） |
| 類型 | 肉鴿（Roguelite）＋ 除草（Survivors-like / 割草）動作遊戲 |
| 一句話描述 | 扮演一名被企業追殺的賽博浪人，在霓虹都市的廢墟中，用刀與義體斬殺成千上萬的敵人，存活到黎明。 |
| 核心體驗 | 「從弱小到割草如麻」的爽快成長感，加上每局不同的 Build 組合 |
| 平台 | **手機優先，直式 9:16**（iOS / Android）；開發中可直接用手機瀏覽器測試 |
| 單局時長 | **10 分鐘** |
| 商業模式 | **免費下載＋內購**，不賣數值（見第 6 章） |
| 介面語言 | 繁體中文、英文 |
| 目標玩家 | 喜歡 Vampire Survivors、Brotato、Halls of Torment 類型的玩家；利用碎片時間玩的手機玩家 |

## 2. 設計目標

1. **10 秒上手**：單手拖曳移動，攻擊全自動。
2. **持續的成長快感**：每 20～40 秒就有一次升級選擇。
3. **Build 多樣性**：武器 × 被動 × 進化，每局都能玩出不同流派。
4. **局外長期動機**：解鎖角色、武器、永久強化，讓失敗也有收穫。
5. **獨特的主題與招牌機制**：賽博龐克 × 武士，加上「殺意 → 居合一閃」機制。
6. **公平**：付費不影響戰力。

## 3. 核心玩法循環

```
局內（Run，10 分鐘）：
  移動走位 → 自動攻擊殺敵 → 撿經驗晶片 → 升級 → 三選一強化
       ↑                                              ↓
       └──── 敵潮越來越強 / 精英 / Boss ←─────────────┘
  → 撐過 10 分鐘並擊敗最終 Boss（勝利）或死亡（失敗）

局外（Meta）：
  結算獲得信用點 → 永久強化 / 解鎖新角色、武器 → 開始下一局
```

## 4. 局內系統

### 4.1 操作
- 移動：手指在螢幕任意位置拖曳，出現浮動虛擬搖桿（單手可玩）
- 攻擊：**全自動**，玩家只負責走位
- 暫停：畫面角落的暫停鈕；App 切到背景時自動暫停
- 電腦上測試時：WASD / 方向鍵

### 4.2 角色屬性
生命、移動速度、攻擊力、攻擊速度、範圍、投射物數量、持續時間、冷卻縮減、拾取範圍、幸運、護甲、生命回復。

### 4.3 招牌機制：殺意與「居合・一閃」
- 每擊殺一個敵人就累積「殺意」；一段時間沒有擊殺，殺意會慢慢下降
- 殺意集滿時**自動**發動「居合・一閃」：畫面停頓一下，接著一道全螢幕刀光，清掉一般敵人並重創精英與 Boss
- 一閃之後，畫面上所有的經驗晶片會自動吸向玩家（避免晶片被敵人擋住撿不到）
- 殺意值越高，刀光特效越華麗；部分被動道具會影響殺意的累積速度與一閃的威力
- 設計目的：在全自動玩法中創造週期性的爆發高潮，同時鼓勵玩家主動衝進敵群，強化武士的感覺

### 4.4 武器（完整版 8 把，MVP 4 把；每把可升到 Lv.8）
| 武器 | 攻擊方式 | MVP |
|---|---|---|
| 高周波刀 | 自動朝最近的敵人扇形斬擊；附近沒有敵人時朝移動方向（初始武器） | ✅ |
| 苦無無人機 | 環繞玩家旋轉 | ✅ |
| 電漿手裡劍 | 彈射穿透投射物 | ✅ |
| 電磁結界 | 玩家周圍持續傷害的光圈 | ✅ |
| 雷射居合 | 朝敵人射出貫穿的直線光刃 | |
| 駭入病毒 | 感染敵人持續傷害；感染者死亡時擴散給附近敵人 | |
| 軌道打擊 | 鎖定畫面上的敵人，預警後從天而降轟炸 | |
| 鎖鏈鉤爪 | 鉤住敵人，連同周圍雜兵一起拉到面前 | |

### 4.5 被動道具（完整版 8 個，MVP 4 個）
義體強化（攻擊力）、神經加速器（武器冷卻）、反應裝甲（護甲）、磁力模組（拾取範圍）、光學迷彩（移動速度）、奈米修復（生命回復）、超頻核心（**武器範圍**；原訂的冷卻縮減和神經加速器重複，因此改為範圍）、殺意晶片（殺意累積速度）。

### 4.6 進化系統
滿級武器 ＋ 對應的被動道具 → 擊敗精英掉落的寶箱可讓武器進化為終極武器。
- 高周波刀 ＋ 神經加速器 → 「千本櫻・斬」（360 度迴旋斬）
- 苦無無人機 ＋ 光學迷彩 → 「夜鴉群」（6 架無人機忽遠忽近盤旋）
- 電漿手裡劍 ＋ 超頻核心 → 「風魔大手裡劍」（巨大手裡劍貫穿後飛回）
- 電磁結界 ＋ 反應裝甲 → 「雷神結界」（巨大結界＋落雷）

### 4.7 升級選擇
- 升級時從武器 / 被動道具中隨機給 **3 個選項**
- **重抽**：每局 2 次
- **放逐**（把某個選項永久移出本局選項池）：每局 2 次
- **鎖定**（保留某個選項到下次升級）：每局 1 次
- 次數可以透過局外強化增加
- 欄位上限：**武器 4、被動道具 4**（手機螢幕小，欄位少一點介面比較清楚）

### 4.8 敵人
- **雜兵**：數量多、血量低、追蹤玩家（維安無人機、改造幫派份子、殭屍化義體人）
- **企業槍兵**（M2 新增）：保持距離，用電漿步槍遠程射擊，第 2 分鐘起出現
- **精英**：體型較大、有特殊攻擊，會掉落寶箱
- **Boss**：第 3、6 分鐘各一隻，最終 Boss 在第 9:30 出現
  - 第 3 分鐘「鬼面將軍」（血量 1200）：蓄力衝刺＋環狀彈幕
  - 第 6 分鐘「絡新婦」（血量 4000）：蜘蛛機甲，召喚無人機＋旋轉彈幕
  - 第 9:30「鬼面將軍・極」（血量 9000）：衝刺、環狀與旋轉彈幕全部使用
- 依時間軸配置的波次表；因為直式畫面左右視野窄，敵人生成偏重上下方向

### 4.9 掉落物
經驗晶片（三種大小）、能量包（回血）、磁鐵（吸走全場的經驗）、寶箱、信用點。

### 4.10 勝敗與復活
- 勝利：撐過 10 分鐘並擊敗最終 Boss
- 失敗：生命歸零
- **復活：每局 1 次**，免費，原地復活、回滿血並清空周圍敵人

## 5. 局外系統（Meta Progression）
- **貨幣**：每局結算依存活時間、擊殺數、Boss 擊殺數獲得「信用點」
- **永久強化**（義體強化中心）：攻擊 +5%、最大生命 +10、移動 +3%、拾取 +10%、經驗 +5%（各 5 級），重抽／放逐 +1（各 3 級）、鎖定 +1（2 級）；價格隨等級提高
- **結算獎勵**：存活秒數 ÷ 6 ＋ 擊殺 ÷ 20 ＋ 每隻 Boss 25 ＋ 勝利 100（另加局內撿到的信用點）
- **角色：初版 3 名**，各有不同的初始武器與特性

| 角色 | 定位 | 初始武器 | 特性 |
|---|---|---|---|
| 浪人・刃 | 平衡型（預設角色） | 高周波刀 | 殺意累積 +20% |
| 駭客・零 | 遠程控制型 | 電漿手裡劍 | 投射物 +1、生命 80（300 信用點解鎖） |
| 重裝・鐵 | 坦克型 | 電磁結界 | 護甲 +3、生命 130、移動較慢（500 信用點解鎖） |

- **武器與被動道具解鎖**：達成成就後才會出現在升級選項中
  - 雷射居合：累計擊殺 1000｜駭入病毒：擊敗任一 Boss｜軌道打擊：單局存活 8 分鐘｜鎖鏈鉤爪：單局 Lv 25
  - 奈米修復：累計遊玩 3 局｜殺意晶片：累計發動一閃 15 次
- **圖鑑**：收錄已發現的武器、敵人、進化
- **劇情**：只有角色背景文字與敵人圖鑑描述，不做過場動畫
- **地圖：初版 1 張**（霓虹貧民窟）；多張地圖與難度等級放到上線後更新
- **紀錄**：本機的最佳存活時間、最高擊殺數；初版不做線上排行榜

## 6. 商業模式：免費＋內購

**原則（v1.3 修訂）：付費可以抽戰力，但要公平透明。**
- 抽卡（見第 13 章 B2）可用真錢購買的「晶片」抽，也可用遊戲內取得的晶片抽；免費玩家靠每日任務、成就、Boss 也能穩定取得晶片
- 一定要有保底（十連必出 SR、50 抽必出 SSR），並在遊戲內公開各稀有度機率（台灣機率型商品規定、Apple／Google 上架規定）
- 禁止付費抽獎的地區（例如比利時）關閉付費抽卡
- 外觀、角色解鎖、支持者包維持原規劃

| 內購項目 | 內容 |
|---|---|
| 角色解鎖 | 直接購買角色（也可以用信用點慢慢解鎖，付費只是省時間） |
| 外觀造型 | 角色換色、刀光特效、「一閃」特效、擊殺特效 |
| 支持者包 | 一次性購買：專屬外觀＋結算信用點永久 +20%（只加快解鎖速度，不影響戰力上限） |

- **廣告**：只有玩家**自願觀看**的獎勵廣告，看完可讓結算信用點加倍；沒有強制廣告，買支持者包也不會因此移除任何東西
- **賽季通行證**：初版不做，上線後依營運數據再評估
- 技術：Capacitor 內購外掛（例如 RevenueCat），購買紀錄需要後端驗證
- 需要：Apple / Google 開發者帳號、隱私權政策、未成年人消費提示
- 階段：MVP 不做內購與廣告，Beta 前再接上

## 7. 美術與音效

### 7.1 風格
- **2D 像素風**（16-bit）、俯視角，霓虹配色（洋紅、青、紫）搭配暗色背景
- 定案風格參考圖：`art/style-refs/style-A-selected.png`（霓虹貧民窟），所有素材都以它為參考圖生成
- 打擊感：震屏、閃白、傷害數字、爆炸粒子、「一閃」時畫面停頓
- 音樂：Synthwave / 電子樂 ＋ 和風樂器（尺八、太鼓）

### 7.2 素材製作流程（全部用 Higgsfield 生成，包含音樂與音效）
1. **定風格**：先生成一張主視覺／風格參考圖，確認後作為之後所有素材的參考圖
2. **角色**：生成角色設定圖，再產出遊戲用的精靈圖（待機、移動、受傷、死亡）
3. **敵人、Boss、掉落物、武器圖示、UI**：沿用同一張參考圖逐一生成，再去背
4. **轉成遊戲可用格式**：去背 → 縮放並對齊像素網格 → 打包成 Sprite Atlas
5. **音樂與音效**：用 Higgsfield 的音訊生成功能製作戰鬥 BGM、Boss BGM、選單 BGM，以及各種音效
6. **宣傳素材**：商店截圖、預告影片

- AI 生成的連續動畫影格不容易保持一致；做不到的地方會改用少量影格，加上程式補間（壓扁拉伸、閃爍、殘影）
- 生成會消耗 Higgsfield 點數，每一批生成前會先估算點數、經過你同意才執行
- 開發順序：MVP 先用色塊佔位，確認好玩後再整批生成素材

## 8. 技術需求
- 引擎：**Phaser 3 + TypeScript + Vite**，用 **Capacitor** 打包成 iOS / Android App
- 效能目標：中階手機同屏 300+ 敵人維持 60 FPS（物件池、空間格網碰撞、限制粒子數量）
- 省電模式：30 FPS、減少特效
- 畫面：直式 9:16，自適應各種長寬比，避開瀏海與手勢列（安全區域）；UI 按鈕最小 44pt，單手可觸及
- 存檔：本機存檔（網頁版用 localStorage，App 版用 Capacitor Preferences）
- 數值設定：武器、敵人、波次都寫在 JSON 設定檔，方便調整平衡
- 多語系：所有文字都放在語系檔（zh-TW、en）
- 開發工具：除錯面板（無敵、跳時間、直接給武器）

## 10. 成功指標
- 首局完成率 > 70%
- 平均每次遊玩局數 ≥ 3
- 次日留存 > 30%、7 日留存 > 12%
- 付費轉換率 2～5%（免費＋內購遊戲的常見區間）

## 11. 風險
| 風險 | 對策 |
|---|---|
| 手機上同屏大量敵人效能不足 | 物件池、空間格網碰撞、省電模式 |
| 數值失衡，導致無聊或太難 | 數值集中在 JSON 設定檔；除錯面板 |
| AI 素材畫風不一致 | 固定一張風格參考圖；統一後製（調色、描邊、像素化） |
| 直式畫面視野窄，難以閃避 | 鏡頭拉遠、敵人生成偏重上下方向、畫面外的敵人加上箭頭提示 |
| 內購審核與合規 | 預留審核時間；不賣數值，降低爭議 |
| 同類遊戲多，缺乏辨識度 | 賽博武士主題＋「殺意 → 居合一閃」招牌機制 |

## 13. M2.5 擴充內容設計

### A1. 升級卡稀有度
| 稀有度 | 顏色 | 基礎機率 | 效果倍率 |

### A2. 遺物與詛咒
- 精英寶箱與 Boss 掉落「遺物三選一」（取代原本的隨機升級；進化仍優先）
- 一局最多 6 個遺物；初版 20 個（15 個一般、5 個詛咒）
- 詛咒：強力但有代價，例如「敵人數量 +50%，所有獎勵 +50%」「最大生命減半，攻擊 +60%」
- 遺物圖示由 Higgsfield 生成

### A3. 羈絆
- 武器屬性：刃（高周波刀、雷射居合、鎖鏈鉤爪）、電（電磁結界、苦無無人機）、駭（駭入病毒、電漿手裡劍）、炎（軌道打擊）
- 2 件：小加成；4 件：特殊效果（例如電 ×4：攻擊 15% 機率麻痺 1 秒）
- HUD 顯示目前羈絆

### A4. 精英詞綴
- 精英隨機 1～2 個詞綴：爆裂、護盾、分裂、狂暴、召喚；第 5 分鐘後可能出現 2 個
- 詞綴越多，掉落的遺物越可能是高稀有度

### A5. 黑市商人與事件
- 第 2、5、8 分鐘左右出現黑市商人：用局內信用點購買（遺物、回血、重抽、升級卡）
- 隨機事件（每局 2～3 次）：賭命祭壇（扣 30% 生命換一張金卡）、駭入終端（站在範圍內 3 秒，免費升級一把武器）、補給空投

### D1. 打擊感
- 打中精英／Boss 時短暫停頓（約 40 毫秒）、暴擊大字、COMBO 連段計數、敵人死亡碎裂
- 手機震動回饋（設定可關閉）
- 新增「暴擊率」屬性（基礎 5%，暴擊傷害 ×2）

### C2. 通緝等級
- 第一次通關後解鎖，共 10 級；每級加一條規則，例如敵人血量 +20%、精英變多、Boss 新招式、回血減半
- 結算獎勵倍率：1 + 0.2 × 等級（最高 ×3）

### B1. 義體模組
- 欄位：頭部晶片、軀幹裝甲、手臂義肢
- 稀有度 N／R／SR／SSR：主屬性固定，副屬性 0／1／2／3 條隨機
- 強化 +0～+10，用「零件」強化；分解多餘模組換零件
- 來源：Boss（必掉）、精英（20%）、抽卡；通緝等級越高，掉落的稀有度越高
- 實作：12 種基本模組（每個欄位 4 種），稀有度用外框顏色區分；強化 +0～+10 每級主屬性 +12%、副屬性 +5%

### B2. 抽卡「黑市義體販賣機」
- 單抽 100 晶片、十連 900 晶片
- 機率：N 60%／R 30%／SR 8.5%／SSR 1.5%；十連保底至少 1 張 SR；50 抽內必出 SSR（保底計數跨卡池保留）
- 卡池：模組池（常駐）、角色碎片池（之後加）
- 遊戲內有機率表頁面
- 晶片來源：每日任務（每天約 180）、30 個成就、每日挑戰首次通關（100）、每局擊敗 Boss（每隻 10）與通關（30）；新存檔送 300 晶片；M3 接上付費購買

### B5. 每日任務、成就、每日挑戰
- 每日 3 個任務，獎勵晶片；30 個成就
- 每日挑戰：依日期決定角色（免解鎖）、通緝等級 1～3 與隨機種子，記錄當天最佳；每日挑戰通關不會解鎖一般通緝等級
