## 1. 與既有產品的差異

| 面向 | 常見同類（走停射擊） | 本作 |
|---|---|---|
| 操作 | 即時搖桿移動 | **暫停畫路線、放手後執行**：每一段都是一次小規劃，攻擊全自動 |
| 角色 | 單一英雄 / 排成長條的隊伍 | **最多 7 隻動物圍成陣形**，各有武器與血量；陣形越大火力越強、也越容易被打中 |
| 失敗壓力 | 只有一條血 | 夥伴會倒下脫隊（營火可救回），隊長倒下才失敗 |
| 肉鴿選擇 | 技能三選一 | **招募誰、幫誰升星、全隊強化、合體技**，打造自己的隊伍 |
| 關卡 | 線性房間 | **分岔地圖**：戰鬥 / 菁英 / 救援 / 營火 / 寶箱 / 行商，自己規劃路線 |
| 局外 | 裝備 + 天賦 | 裝備 + **動物村莊**（蓋房子解鎖夥伴與永久加成） |

## 2. 核心循環

```
30 秒   畫路線避開預告的攻擊 → 夥伴自動攻擊 → 撿經驗與金幣 → 升級三選一
1 層    在地圖上選下一個節點：戰鬥、救援、營火、寶箱、行商、菁英
1 局    9 層地圖（約 5～8 分鐘），第 8 層營火、第 9 層 Boss
1 天    帶回金幣與裝備 → 強化裝備、蓋村莊 → 隊伍更強 → 走得更遠
7 天    嘉年華任務 → 積分 → 傳說魔杖
```

## 3. 戰鬥

### 3.1 操作
- 戰鬥分成兩個階段循環：
  - **規劃**：時間暫停。在任何地方按住拖曳，畫出隊長接下來的路線（相對畫法，手指不會擋住隊伍）。路線長度受「墨水」限制，墨水 = 移動速度 × 1.75。
  - **行軍**：放手後時間恢復，隊長以移動速度 × 1.3 沿路線前進，敵人同時行動；走完自動回到規劃。
- 只點一下不畫線 = 原地堅守 0.9 秒。
- 規劃時會顯示預告：敵人子彈接下來的飛行軌跡、敵人移動方向的紅色箭頭。
- 場上沒有敵人時（波次之間、清場撿東西）時間照常流動，不需要畫線。

### 3.2 隊伍
- 夥伴圍在隊長身邊：內圈 6 隻、外圈再放 1 隻，移動時平滑跟上。
- 每位隊員有獨立血量；敵人會攻擊**最靠近的隊員**。
- 隊員倒下會脫隊，該場戰鬥不再攻擊；營火、野餐便當、復活可救回。
- 隊長倒下 → 可看廣告 / 💎30 復活一次（隊長滿血、倒下的夥伴 50% 回歸）。

| 綠 | 🐱 火球貓咪 | 森林 | 火球爆炸 + 燃燒 |
| 綠 | 🐧 雪球企鵝 | 雪地 | 雪球範圍減速 |

### 3.3.1 陣營羈絆
隊伍中同陣營夥伴達到門檻即生效（地圖、升級、暫停畫面都會顯示）：

| 陣營 | 2 隻 | 3 隻 |
|---|---|---|
| 🌳 森林 | 全隊生命 +15% | 生命 +30%，每 5 秒回 3% |
| 🌊 海洋 | 攻速 +12% | 攻速 +25% |
| ❄️ 雪地 | 敵人移速 -15% | 敵人 -25%，爆擊率 +12% |
| ☁️ 天空 | 撿取範圍 +50%、移動 +10% | 全隊攻擊 +20% |

### 3.4 三選一卡片（`src/data/skills.ts`）

| 類別 | 內容 |
|---|---|
| 新夥伴 | 招募一隻尚未在隊伍中的已解鎖夥伴（隊伍少於 3 隻時權重較高） |
| 升星 | 指定夥伴 +1 星並回滿血 |
| 全隊強化 | 團隊特訓、興奮點心、輕快腳步、大胃王、野餐便當、吸吸磁鐵、幸運四葉草、致命爪擊、吃飽飽 |
| **合體技（金卡）** | 火狐流星（貓 3 星 + 狐）、暴雪兔兔（兔 3 星 + 企鵝）、熊熊守護（熊 3 星 + 倉鼠）、團結之星（隊長 3 星 + 隊伍 4 隻以上） |

每局重抽次數 = 1 + 村莊瞭望塔等級（每次需看廣告，模擬）。

### 3.5 敵人與 Boss
沿用 v0.1：追擊、射手、衝刺、環形彈、跳躍等 8 種一般怪，2 種菁英（召喚、螺旋彈幕），2 種 Boss（50% 血進入二階段）。敵人鎖定最近的隊員。

### 3.6 戰鬥節點
- 一般戰鬥：2～3 波，場上剩 1 隻或 14 秒後下一波。
- 菁英：一波小怪 + 菁英，必掉一件裝備。
- Boss：章節頭目。

## 6. 局外養成

### 6.1 裝備（`src/data/equipment.ts`）
隊長的四件裝備（武器、護甲、戒指、項圈）強化整支隊伍。六階品質、三合一、強化、一鍵合成，同 v0.1。

### 6.2 夥伴召喚（`src/data/gacha.ts`）

| 卡池 | 機率（白/綠/藍/紫/金/紅） | 保底 |
|---|---|---|
| 常駐召喚 | 40 / 30 / 18 / 9 / 3 / 0 % | 50 抽內必得傳說 |
| 限時召喚（每週輪替：小火龍 → 獨角獸 → 熊貓 → 海豚） | 38 / 30 / 18 / 9 / 4 / 1 % | 60 抽內必得主打；主打佔其稀有度 50% |

- 單抽 💎200、十連 💎1800（十連最後一抽保底稀有以上），可用召喚券代替。
- 每日看廣告免費單抽 1 次；新帳號免費十連 1 次（保底史詩以上）。
- 重複夥伴轉碎片：白 10、綠 15、藍 20、紫 30、金 50、紅 80。
- 遊戲內「機率說明」列出每個稀有度與每隻夥伴的實際機率。

### 6.2.1 夥伴永久等級（碎片）與覺醒
- 7 種夥伴各有永久等級 Lv1～10，每級讓牠在冒險中的傷害與生命 +10%。
- 升級消耗碎片（10 / 20 / 35 / 55 / 80 / 110 / 150 / 200 / 260）與金幣（250 × 等級²）。
- 碎片來源：每場戰鬥 1 片、菁英 4 片、寶箱節點 3 片、Boss 10 片（給隊伍中隨機一位）；夥伴蛋；每日免費蛋。
- 尚未在村莊解鎖的夥伴可以先累積碎片。
- **覺醒**：Lv5 覺醒Ⅰ（腳下稀有度色光環，能力再 +10%）、Lv10 覺醒Ⅱ（閃光粒子與 ✨，能力再 +20%）。若有 `partner_<id>_awaken.png` 圖片，覺醒後自動換成覺醒造型。

### 6.3 動物村莊（`src/data/village.ts`）

| 建築 | 效果 | 上限 |
|---|---|---|
| 🏟️ 訓練場 | 全隊攻擊 +6% / 級 | 10 |
| 🏥 醫療小屋 | 全隊生命 +7% / 級 | 10 |
| 🏡 招募所 | Lv1 救援 3 選 1、Lv2 出發自帶夥伴、Lv3 自帶夥伴 2 星、Lv4 隊伍上限 +1（7 隻）、Lv5 自帶夥伴 3 星 | 5 |
| 🌾 金幣糧倉 | 冒險金幣 +10% / 級 | 8 |
| 🗼 瞭望塔 | 每局重抽 +1 / 級 | 3 |

- 一位建築師，一次只能蓋一棟。
- 費用 = 基礎 × 1.65^等級；時間 = 20 秒 × (等級+1)^1.6（Lv1 20 秒、Lv10 約 15 分鐘）。
- 加速：看廣告 -5 分鐘（每次建造一次）、或鑽石立即完成（每分鐘 3 💎）。

3. 寶箱公開機率與保底。
4. 限時是真的限時。

## 8.2 每日任務與戰令（`src/data/daily.ts`）

- **每日任務**（每天 0 點重置）：登入、完成 3 場戰鬥、擊倒 80 個敵人、召喚 1 次、升級 1 次，各 20 活躍度；活躍度 40 / 70 / 100 開寶箱（金幣 / 鑽石 / 召喚券）。
- **戰令**：28 天一季、20 級、每級 100 經驗。經驗來源：每日任務活躍度、每場戰鬥 +5、每次冒險 +10。免費線：金幣、鑽石、每 5 級召喚券；豪華線：碎片、鑽石、召喚券，Lv10 獨角獸碎片 ×50、Lv20 小火龍碎片 ×80。
- 入口：大廳左側「任務・戰令」按鈕。

## 10. 數值驗證（自動機器人）

`?bot=1&speed=8`：機器人自動走地圖、閃避、撿東西、選第一張卡。

| 情境 | 結果 |
|---|---|
| 新帳號（不抽卡、初始 4 隻夥伴） | 5 局通關 2 局，其餘都打到 Boss 才失敗（Boss 剩 16～67%） |
| 7 隻新夥伴同隊（含海洋 3、天空 3 羈絆） | 7 種新武器運作正常、無錯誤 |

> 新手免費十連保底史詩，實際玩家首通第一章機率會比機器人高；第二章（敵人血量 ×2.4）是主要的數值牆。
