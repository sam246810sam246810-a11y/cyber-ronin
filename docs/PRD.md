# Cyber Ronin — 產品需求文件（PRD）v0.1 草案

> 狀態：草案 v0.3。已確認：賽博龐克武士題材、手機優先（直式）、全自動攻擊、Phaser 3 + TypeScript（用 Capacitor 打包）、單局 10 分鐘、免費＋內購、美術素材全部用 Higgsfield 生成。標 **【待確認】** 的部分是我先假設的，需要你決定。

---

## 1. 產品概述

| 項目 | 內容 |
|---|---|
| 暫定名稱 | Cyber Ronin（賽博浪人） |
| 類型 | 肉鴿（Roguelite）＋ 除草（Survivors-like / 割草）動作遊戲 |
| 一句話描述 | 扮演一名被企業追殺的賽博浪人，在霓虹都市的廢墟中，用刀與義體斬殺成千上萬的敵人，存活到黎明。 |
| 核心體驗 | 「從弱小到割草如麻」的爽快成長感，加上每局不同的 Build 組合 |
| 平台 | **手機優先，直式畫面**（iOS / Android）；開發中可直接用手機瀏覽器測試 |
| 商業模式 | **免費下載＋內購**（見第 6 章） |
| 單局時長 | **10 分鐘**（第 3、6 分鐘各一隻 Boss，第 9:30 出最終 Boss） |
| 目標玩家 | 喜歡 Vampire Survivors、Brotato、Halls of Torment 類型的玩家；碎片時間的休閒玩家 |

## 2. 設計目標

1. **10 秒上手**：只需移動，攻擊自動進行（或極簡操作）。
2. **持續的成長快感**：每 20～40 秒就有一次升級選擇。
3. **Build 多樣性**：武器 × 被動 × 進化，每局都能玩出不同流派。
4. **局外長期動機**：解鎖角色、武器、永久強化，讓失敗也有收穫。
5. **獨特的主題**：賽博龐克 × 武士，與市場上眾多奇幻題材區隔。

## 3. 核心玩法循環

```
局內（Run）：
  移動走位 → 自動攻擊殺敵 → 撿經驗晶片 → 升級 → 三選一強化
       ↑                                              ↓
       └──── 敵潮越來越強 / 精英 / Boss ←─────────────┘
  → 存活到時間結束（勝利）或死亡（失敗）

局外（Meta）：
  結算獲得貨幣 → 商店永久強化 / 解鎖新角色、武器 → 開始下一局
```

## 4. 局內系統

### 4.1 操作
- 移動：手指在螢幕任意位置拖曳，出現浮動虛擬搖桿（單手可玩）
- 攻擊：**全自動**，玩家只負責走位
- 暫停：畫面角落的暫停鈕；App 切到背景時自動暫停
- 電腦上測試時：WASD / 方向鍵

### 4.2 角色屬性
生命、移動速度、攻擊力、攻擊速度、範圍、投射物數量、持續時間、冷卻縮減、拾取範圍、幸運、護甲、生命回復。

### 4.3 武器（初版 6～8 把，每把可升到 Lv.8）
| 武器 | 攻擊方式 |
|---|---|
| 高周波刀 | 面向方向的扇形斬擊 |
| 苦無無人機 | 環繞玩家旋轉 |
| 電漿手裡劍 | 彈射穿透投射物 |
| 雷射居合 | 隨機方向直線穿刺 |
| 電磁結界 | 玩家周圍持續傷害光圈 |
| 駭入病毒 | 讓敵人感染並連鎖擴散 |
| 軌道打擊 | 隨機位置從天而降的轟炸 |

### 4.4 被動道具（初版 6～8 個）
例：義體強化（攻擊力）、神經加速器（攻速）、反應裝甲（護甲）、磁力模組（拾取範圍）……

### 4.5 進化系統
滿級武器 ＋ 指定被動 → 開寶箱進化為終極武器（例：高周波刀 ＋ 神經加速器 → 「千本櫻・斬」）。

### 4.6 升級選擇
- 升級時從武器 / 被動中隨機給 3 個選項
- 【待確認】是否提供「重抽」「放逐」「鎖定」等功能
- 武器欄位上限 6、被動上限 6 【待確認】

### 4.7 敵人
- **雜兵**：大量、低血、追蹤玩家（維安無人機、改造幫派份子、殭屍化義體人）
- **精英**：體型較大、會掉落寶箱
- **Boss**：第 3、6 分鐘各一隻，最終 Boss 在第 9:30 出現
- 敵潮依時間軸配置（波次表）

### 4.8 掉落物
經驗晶片（三種大小）、能量包（回血）、磁鐵（吸全場經驗）、寶箱、局內金幣。

### 4.9 勝敗條件
- 勝利：存活滿時間 / 擊敗最終 Boss
- 失敗：生命歸零
- 【待確認】是否有「復活」機制

## 5. 局外系統（Meta Progression）
- **貨幣**：每局結算獲得「信用點」
- **永久強化商店**：各屬性小幅提升（有等級上限）
- **角色解鎖**：初版 3 名角色，各有不同初始武器與被動特性
- **武器 / 道具解鎖**：透過達成成就解鎖，逐步擴充道具池
- **圖鑑**：已發現的武器、敵人、進化
- 【待確認】是否需要多張地圖 / 難度等級

## 6. 商業模式：免費＋內購

**原則：不賣數值、不做 Pay-to-Win**，以免破壞肉鴿遊戲的成就感與口碑。【待確認】

| 內購項目 | 內容 | 備註 |
|---|---|---|
| 角色解鎖 | 直接購買角色（也可以用遊戲內貨幣慢慢解鎖） | 付費只是省時間 |
| 外觀造型 | 角色換色、刀光特效、擊殺特效 | 純外觀 |
| 賽季通行證 | 免費線＋付費線，獎勵為外觀與貨幣 | 【待確認】初版是否需要 |
| 去廣告／支持者包 | 一次性購買 | 如果有廣告才需要 |
| 遊戲內貨幣（晶片） | 用來購買外觀 | 【待確認】是否開放直接儲值 |

- 技術：Capacitor 內購外掛（例如 RevenueCat），購買紀錄需要後端驗證
- 需要：Apple / Google 開發者帳號、隱私權政策、未成年人消費提示
- 階段：MVP 不做內購，Beta 前再接上

## 7. 美術與音效

### 7.1 風格
- 風格：【待確認】2D 像素風或手繪風、俯視角，霓虹配色（洋紅、青、紫）
- 畫面特效：大量殺敵時的打擊感（震屏、閃白、傷害數字、爆炸粒子）
- 音樂：Synthwave / 電子 ＋ 和風樂器（尺八、太鼓）

### 7.2 素材製作流程（全部用 Higgsfield 生成）
1. **定風格**：先生成一張「主視覺／風格參考圖」，確認後作為之後所有素材的參考圖，維持畫風一致
2. **角色**：生成角色設定圖，再產出遊戲用的精靈圖（待機、移動、受傷、死亡）
3. **敵人、Boss、掉落物、武器圖示、UI**：沿用同一張參考圖逐一生成，再去背
4. **轉成遊戲可用格式**：去背 → 縮放到固定尺寸 → 打包成 Sprite Atlas
5. **音樂與音效**：用 Higgsfield 的音訊生成功能製作 BGM 與音效 【待確認】
6. **宣傳素材**：商店截圖、預告影片

- 注意：AI 生成的連續動畫影格不容易保持一致；做不到的地方會改用少量影格，加上程式補間（壓扁拉伸、閃爍、殘影）
- 注意：生成會消耗 Higgsfield 點數，每一批生成前會先估算點數、經過你同意才執行
- 開發順序：MVP 先用色塊佔位，確認好玩後再整批生成素材，避免改了玩法還要重做美術

## 8. 技術需求
- 引擎：**Phaser 3 + TypeScript + Vite**，用 **Capacitor** 打包成 iOS / Android App（開發時用瀏覽器就能測，打包後就是原生 App）
- 效能目標：中階手機同屏 300+ 敵人維持 60 FPS（需物件池、空間格網碰撞、限制粒子數量）
- 電量與發熱：提供「省電模式」（30 FPS、減少特效）
- 存檔：本地存檔（localStorage）
- 畫面方向：**直式 9:16**（直式畫面左右視野較窄，因此敵人生成會偏重上下方向，並把鏡頭稍微拉遠）
- 自適應各種長寬比，避開瀏海與手勢列（安全區域）
- UI 按鈕最小 44pt，單手可觸及

## 9. 範圍與里程碑

### MVP（第一個可玩版本）
- 1 名角色、1 張地圖、4 把武器、4 個被動、1 種進化
- 3 種雜兵、1 種精英、1 個 Boss
- 升級三選一、10 分鐘一局、結算畫面
- 佔位美術；可在手機瀏覽器上試玩

### Alpha
- 3 角色、8 武器、8 被動、4 進化
- 局外商店與解鎖
- 用 Higgsfield 生成正式美術與音效

### Beta / 上線
- 內購、多地圖、難度、成就、平衡調整、多語系
- 上架 App Store / Google Play

## 10. 成功指標
- 首局完成率 > 70%
- 平均每次遊玩局數 ≥ 3
- 次日留存 > 30%
- 付費轉換率 2～5%（免費＋內購遊戲的常見區間）

## 11. 風險
| 風險 | 對策 |
|---|---|
| 同屏大量敵人效能不足 | 物件池、空間格網碰撞、必要時降低特效 |
| 數值失衡導致無聊或太難 | 數值集中在設定檔，方便調整；加入除錯面板 |
| 美術工作量大 | MVP 先用佔位素材驗證好不好玩 |
| AI 素材畫風不一致 | 固定一張風格參考圖；統一後製（調色、描邊） |
| 內購審核與合規 | 預留審核時間；不賣數值降低爭議 |
| 同類遊戲多、缺乏辨識度 | 強化賽博武士主題與獨特機制（見待確認問題） |
