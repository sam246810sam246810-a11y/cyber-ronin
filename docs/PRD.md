# 萌爪突擊 PAW STRIKE — 產品需求文件 v0.1（M1）

| 項目 | 內容 |
|---|---|
| 類型 | 直式單指・走停射擊・Roguelike + 數值養成 |
| 題材 | 可愛動物（柴犬小英雄 vs 調皮森林動物） |
| 平台 | Web（手機瀏覽器優先），之後以 Capacitor 包成 iOS / Android |
| 技術 | TypeScript + Canvas 2D + Vite，無遊戲引擎依賴 |
| 美術 | M1 使用幾何 + emoji 佔位；正式美術由 Higgsfield 生成（清單見 [ASSETS.md](ASSETS.md)） |
| 商業化 | 合規版，M1 全部為模擬金流 |

---

## 1. 設計目標

參考 Habby 系產品的成功公式，拆成四根支柱：

| 支柱 | 本作做法 | M1 狀態 |
|---|---|---|
| 單手操作 + 即時正反饋 | 單指浮動搖桿；移動時閃避，**停下自動瞄準射擊**；完整打擊感清單（見 §4） | ✅ |
| 肉鴿三選一 + 超武 | 每升一級三選一；條件達成出現金卡「超武」 | ✅ 18 技能 + 3 超武 |
| 數值卡關 + 情境付費 | 前 70% 爽快割草，菁英 / Boss 為數值檢定；失敗且「差一點」時彈出突破禮包 | ✅ |
| RPG 深度養成 | 六階裝備三合一、強化、7 日嘉年華 | ✅ |

### 合規原則（已與需求方確認）

1. **錨定只用真實價值**：禮包價值以「商店實際售價」計算（例：300 鑽石在商店需 NT$90），不使用虛構原價。
2. **嘉年華免費可達**：免費任務總積分 > 最終大獎門檻，加速包只是省時間。
3. **機率公開**：寶箱顯示各稀有度機率與保底。
4. **限時是真的限時**：突破禮包倒數結束即消失，24 小時內不重複觸發。

## 2. 核心循環

```
30 秒   移動閃避 → 停下射擊 → 擊倒 → 經驗 → 升級三選一
5 分鐘  15 個房間：1-4 割草 → 5 菁英 → 6-9 → 10 菁英 → 11-14 → 15 Boss
1 天    冒險拿金幣 / 裝備 → 強化 / 合成 → 戰力提升 → 挑戰更遠
7 天    嘉年華任務 → 積分 → 傳說武器
```

## 3. 戰鬥系統

### 3.1 操作
- 手指按住任意處出現浮動搖桿，拖曳移動；放開後角色停下並自動射擊最近、**且無障礙物遮擋**的敵人。
- 桌機支援 WASD / 方向鍵。

### 3.2 房間
- 單一畫面房間，含障礙物（擋子彈、擋移動，飛行敵人可越過）。
- 清空後頂部門開啟，金幣自動吸附，走進門進入下一間。

### 3.3 技能（`src/data/skills.ts`）

| 類別 | 技能 |
|---|---|
| 彈道 | 連發星星、斜向散射、背後護衛、左右開弓、彈跳星、貫穿、反彈牆 |
| 屬性 | 攻擊強化、急速射擊、幸運一擊、致命爪擊、大胃王、美味便當、吃飽飽 |
| 元素 | 火焰彈（燃燒）、冰霜彈（減速）、雷電彈（連鎖）、守護葉片（環繞） |
| **超武** | 太陽火球（火焰 2 + 攻擊 1）、花瓣風暴（葉片 2 + 攻速 1）、雷神之鏈（雷電 2 + 彈跳 1） |

- 三選一依權重隨機；條件達成時保證出現一張超武金卡。
- 每局一次「看廣告重抽」（模擬）。

### 3.4 敵人（`src/data/enemies.ts`）

| 類型 | 敵人 | 行為 |
|---|---|---|
| 追擊 | 蘑菇寶寶 | 搖擺接近 |
| 射手 | 調皮蜜蜂、貓頭鷹法師 | 飛行遊走，預警後瞄準射擊 |
| 衝刺 | 衝衝刺蝟、滑行企鵝 | 紅線預警後衝刺，撞牆反彈 |
| 其他 | 慢吞蝸牛、橫行螃蟹、跳跳青蛙 | 環形彈 / 橫移扇形 / 跳躍落地彈 |
| 菁英 | 蘑菇國王、蜂后女王 | 環形彈幕、螺旋、召喚 |
| Boss | 浣熊大盜、野豬將軍 | 多招式循環，50% 血進入二階段 |

### 3.5 章節（`src/data/chapters.ts`）

| 章節 | 敵人血量倍率 | 傷害倍率 | 推薦戰力 |
|---|---|---|---|
| 1 陽光草原 | ×1 | ×1 | 1,200 |
| 2 椰子海灘 | ×2.4 | ×1.6 | 2,600 |
| 3 棉花糖雪山 | ×5.2 | ×2.5 | 5,000 |

## 4. 打擊感清單

| 項目 | 實作 |
|---|---|
| 受擊閃白 | 白色剪影疊加 90ms |
| 受擊形變 + 擊退 | 擠壓伸展；一般怪擊退大、菁英小、Boss 幾乎不動 |
| 傷害數字 | 物件池；爆擊放大、黃色、彈跳；燃燒橘色、回血綠色 |
| 頓幀（Hit-stop） | 擊殺 25ms、菁英 120ms、Boss 350ms、玩家受傷 60ms |
| 震屏 | 爆擊、受傷、Boss 招式、爆炸 |
| 金幣吸附 | 清房後飛向玩家，音高逐枚上升 |
| 擊殺爆裂 | 擴散環 + 粒子 + 星星 |
| 震動 | `navigator.vibrate`（Android）；可在設定關閉 |
| 音效 | WebAudio 即時合成，無音檔 |
| 預警 | 衝刺紅線、射擊前蓄力形變 |

## 5. 效能

- 固定時間步 60Hz 模擬，渲染跟隨 rAF；掉幀時最多補 4 步。
- 子彈、粒子、金幣、傷害數字全部使用物件池（`src/game/util.ts`），戰鬥中不產生垃圾回收尖峰。
- 精靈圖預先繪製到離屏 Canvas 快取。
- 粒子上限 900。
- `?fps=1` 顯示 FPS 與物件數。

## 6. 局外養成

### 6.1 裝備（`src/data/equipment.ts`）
- 四部位：武器、護甲、戒指、項圈；每部位 2 種模板。
- 六階：普通（白）→ 優秀（綠）→ 稀有（藍）→ 史詩（紫）→ 傳說（金）→ 神話（紅），屬性倍率 1 / 1.5 / 2.2 / 3.2 / 4.6 / 6.5。
- **三合一**：3 件同模板同品質 → 升一階，保留最高等級，被吃掉的強化費退還 50%。
- 強化：金幣，等級上限隨品質提升（10～60）。
- 一鍵合成。

### 6.2 戰力
`攻擊 × 3 × 攻速倍率 × 爆擊期望 + 生命 × 0.5 × (1 + 減傷)`，顯示於大廳與章節推薦值比較。

## 7. 商業化（M1 模擬）

| 模組 | 觸發 / 內容 | 心理機制 |
|---|---|---|
| 突破禮包 NT$30 | 失敗且（Boss 剩 ≤50% 或 已過 10 間房）時彈出；1 小時限時、限購 1、冷卻 24h | 挫折當下的解脫感 |
| 首儲禮 | 首次任何購買送史詩月光戒 | 降低首次付費門檻 |
| 鑽石包首購雙倍 | 每檔各一次 | 錨定 + 稀缺 |
| 黃金寶箱 | 💎300；稀有 70% / 史詩 25% / 傳說 5%；10 抽保底傳說 | 期待感，機率公開 |
| 每日免費 | 木箱 1 次、看廣告領鑽 3 次 | 每日回訪 |
| 復活 | 看廣告或 💎30，每局 1 次 | 沉沒成本 |
| 嘉年華加速包 NT$60 | +40 積分 + 💎300，每日 1 次 | 進度焦慮（但免費可達） |

所有購買都會先跳出「模擬購買，不會扣款」的確認視窗。

## 8. 7 日嘉年華（`src/data/quests.ts`）

- 依首次登入日起算，每天解鎖 4 個任務，共 28 個、**免費總積分 325**（約完成 68% 即可拿到最終大獎）。
- 里程碑：40 金幣 / 80 鑽石 / 120 史詩項圈 / 160 鑽石 / **220 傳說魔杖**。
- 第 8、9 天仍可領取，之後活動關閉。
- 任務累計型（擊倒、房間、強化、合成、開箱、超武、Boss…），提供「前往」按鈕導流到對應系統。

## 9. 數據埋點

本地紀錄最近 500 筆（設定 → 查看最近埋點），之後換成正式 SDK：

`login` `run_start` `room_clear` `skill_pick` `skill_reroll` `death`（含房間、Boss 剩餘血量、**死因與各來源傷害**）`revive` `run_end` `equip_upgrade` `equip_merge` `chest_open` `offer_show` `purchase` `ad_reward` `quest_claim` `milestone_claim`

關鍵漏斗：首局完成率、各房間死亡分佈、突破禮包曝光 → 點擊 → 購買。

## 10. 數值驗證（自動機器人）

`?bot=1&speed=8` 會由簡易 AI 自動遊玩（閃避子彈、繞圈、清房走門），用來快速驗證難度曲線：

| 情境 | 結果（5 局） |
|---|---|
| 新帳號（戰力約 1,000） | 多數死在 7～14 關；有機會打到 Boss 剩一半 → 觸發突破禮包 |
| 全套稀有 Lv15（戰力約 1,900） | 通關率約 75～100% |

> 機器人閃避能力弱於真人，真人通關門檻預期略低；上線後以 `death` 埋點校正。
