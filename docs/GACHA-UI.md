# 抽卡介面改版建議（2026-11-15）

> 現況問題：卡池畫面只有角色疊在一起＋幾行字，看不出「這期主打誰」「為什麼要抽」，按鈕與資訊排得很平。

## A. 主打海報（建議做）

| # | 做法 | 說明 | 點數 |
|---|---|---|---|
| A1 ★ | **雙 SSR 主打** | 神樂、美空兩人用動態立繪並排站在畫面中間，各自有金色名牌（名字、SSR、類型），後方金色光芒；SR 角色縮小排在下方一排頭像 | 0 |
| A2 | 單人輪播 | 一次主打一位 SSR（佔滿畫面），左右滑動切換；適合之後 SSR 變多 | 0 |
| A3 ★ | 卡池主視覺背景 | 每個卡池生成一張專屬背景：角色池＝金色舞台與鳥居、義體池＝黑市實驗室、靈物池＝靈氣森林 | 約 3～4 |

## B. 資訊與按鈕（建議做）

| # | 做法 | 說明 |
|---|---|---|
| B1 ★ | 保底進度條 | 「距離保底 SSR 還有 N 抽」改成一條會發光的進度條，越接近越亮 |
| B2 ★ | 「UP」與機率標籤 | 主打角色旁邊有「UP」角標、「SSR 3%」標籤；十連按鈕上寫「SR 以上保底」 |
| B3 | 卡池分頁做成卡片 | 上方三個卡池分頁改成小縮圖卡片（顯示主打角色或代表圖），選中的會放大發光 |
| B4 ★ | 抽卡券與晶片圖示化 | 持有的券、晶片用圖示＋數量的膠囊顯示，按鈕上也顯示圖示而不是文字 |

## C. 互動（加分）

| # | 做法 | 說明 |
|---|---|---|
| C1 ★ | 點主打角色看介紹 | 跳出角色卡：立繪、能力值、專屬武器、大招說明，以及「試看大招」按鈕（直接播一次大招特寫與特效） |
| C2 | 本期 UP 輪替 | 每週輪流主打不同 SSR，該角色機率提高（例如 SSR 中 70% 是本期 UP 角色），顯示「本期至 週日 23:59」 |
| C3 | 抽卡紀錄 | 一個按鈕看最近 50 抽的結果 |
